Drive I/O investigation now combines read/write throughput, latency and active
time for the physical drive backing the current folder. Both plots use the same
history range, cursor and navigation. Available current health includes the drive
model, temperature, remaining life, powered-on hours, lifetime writes and Windows
health. Missing device facts remain unavailable; virtual and network paths never
borrow measurements from their host or cache disk. Existing approved administrator
access is reused where additional permissions are needed.

Protected folders show an in-pane Access denied explanation, a faint red ribbon
and an action to use the shared administrator session. Switching disk analysis
between Standard and Administrator refreshes its rows and totals without retaining
privileged contents in Standard mode.

Toolbar detail strokes follow the application accent while preserving neutral
outlines, compact proportions and the original terminal lettering.
