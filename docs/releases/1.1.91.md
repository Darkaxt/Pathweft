Pathweft 1.1.91 stops folder sizing from running without end on a busy drive such as C:\ (CORE-28).

- A pane showing C:\ (or a folder holding Users, ProgramData or another folder where something changes every second) could keep one processor core busy indefinitely. When the index service was not ready yet, for example right after an update, the folder sizes were measured on disk, and every change inside a folder during its walk started the walk over.
- Changes inside a folder are now collected for a second, and the changed folders take their totals from the Pathweft index service once it has read the change. Folders the index does not cover are still measured on disk, but a walk interrupted by a change is no longer restarted at once.
- Panes showing a drive root now update their folder sizes when something inside changes; before, they ignored those changes.
- Help (F1) describes where folder sizes come from.

Pathweft 1.1.90 updates to this release with the light package (`Pathweft-1.1.91-update.exe`). Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
