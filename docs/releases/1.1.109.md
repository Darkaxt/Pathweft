Pathweft 1.1.109 wires the preview and the editor to administrator view (ACCESS-10).

- With administrator view on, a file only administrators can read (such as C:\DumpStack.log) previews in the docked card, picture in picture, the floating window and Quick View, instead of "Access to the path is denied". Pathweft reads it through the approved administrator session, from a copy that goes away when the preview moves on (up to 64 MB).
- The editor opens such files the same way (up to 20 MB); saving already used the administrator session.
- A folder only administrators can open shows its contents in the folder preview, including its subfolders when expanded.
- Turning administrator view on or off shows the open previews again with the new access. Network folders keep your own access, as before.
- Help and What's new describe it.

Pathweft 1.1.108 updates to this release with the light package (`Pathweft-1.1.109-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
