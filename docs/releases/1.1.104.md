Pathweft 1.1.104 fixes a crash when copying while another program is using the clipboard (CORE-34).

- Copy path, Copy name, Ctrl+Shift+C, copied details and tables, checksums, recognized text, remote addresses, report rows and the search widget's Copy path no longer close Pathweft when another program holds the Windows clipboard open. The status bar says nothing was copied, and the copy works again once the clipboard is free.
- Comparing a checksum with the clipboard treats a busy clipboard as having no hash.
- What's new and Help describe it.

Pathweft 1.1.103 updates to this release with the light package (`Pathweft-1.1.104-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
