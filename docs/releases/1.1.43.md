Search now submits its asynchronous Everything SDK request when the index
window is temporarily busy and waits for its correlated reply. The previous
advisory window-state check could reject a query while Everything's index was
still available.

This release includes the Maintenance Cleanup work from 1.1.42: quick Scoop
obsolete-version inventory, batched Windows consumer checks, a modeless Clean
progress window, and cancellation between whole-version deletions. Current,
active and persistent package data remain protected.
