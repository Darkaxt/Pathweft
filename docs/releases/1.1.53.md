Pathweft 1.1.53 is a UI refinement release from a full review of the interface's design, responsiveness and motion.

- Large folders stay responsive while their folder sizes arrive. Opening `C:\Windows\WinSxS` used to freeze the window for up to 19 seconds on the test machine; its longest pause is now under a second. Opening and revisiting `System32` responds about twice as quickly.
- Summary cards, the Statistics/Performance switch, Maintenance, Settings categories, Performance details and the preview panel change with a short fade and a slight rise (about 160-200 ms). The change itself happens at once; nothing waits for the animation. Settings → Animations and Windows' animation effects turn it off.
- Folders in the summary cards use a soft Windows folder yellow, matching the folder icons. File-type, age and transfer colours are slightly calmer; the full-drive warning glow is softer.
- An empty folder, a search with no results and a filter that matches nothing now say so in the list.
- Buttons and view choices show keyboard focus, pressed and disabled states. In the light theme, cards are lighter than the page. While the Windows accent is used, the custom accent choices look inactive; choosing one still switches to it. The interface uses the spelling "color" throughout.
- The Drop bin button lines up with the command bar.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
