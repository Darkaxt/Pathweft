Pathweft 1.1.55 fixes two problems in 1.1.54.

- Opening Settings closed Pathweft when app activity recording had never been turned on.
- After updating, Pathweft did not reopen by itself. The same fault made Setup report that the Win+E helper had failed to restart, although it had restarted.

Both came from how Windows reports a sign-in task that does not exist. Pathweft now treats it as absent, and restarting the activity recorder can no longer hold up an update.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
