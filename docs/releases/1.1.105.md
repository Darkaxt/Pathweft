Pathweft 1.1.105 adds batch editing of the details stored inside files (S58: OPUS-09, OPUS-10).

- Right-click → Tools → Edit metadata… edits title, subject, contributing artists, album, album artist, year, track number, genre, authors, tags, rating, comments and copyright for one file or a whole selection. It writes through Windows' own property handlers, as Explorer's Details tab does: JPEG and TIFF photos, MP3, FLAC, M4A and WMA songs, MP4, M4V and WMV videos, and DOCX, XLSX and PPTX documents. Each file is offered only the details its handler can write.
- Every write is read back: a detail a format's handler accepts but doesn't keep is named in that file's result instead of being counted as written. FLAC files aren't offered a rating for this reason.
- Values that differ between the files show as (multiple values) and are kept unless replaced; an emptied field removes the detail.
- Dates sets or shifts the modified, created and date-taken times.
- Review lists every change and the files left alone (read-only, online-only cloud, unsupported, folders) before anything is written. Apply writes file by file with Stop, and the results name each file that failed and why. Nothing is stored beside the files.
- Undo (Ctrl+Z or History → Operation history) puts back each file's earlier details and dates, also after a restart; Operation history records the edit with its real outcome.
- Fixed: extra columns for online-only cloud files asked Windows for a read-write property store instead of cached properties only.
- What's new and Help describe it.

Pathweft 1.1.104 updates to this release with the light package (`Pathweft-1.1.105-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
