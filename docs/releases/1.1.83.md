Pathweft 1.1.83 moves the index service into Pathweft's own installation (S19a, spec 1.44) and removes the duplicate Analyze space menu item (SPACE-01).

- The index service ships in Program Files\Pathweft\services\file_index and is registered there. Setup stops it before replacing its files and starts it again afterwards; the first update moves the earlier registration from Program Files\PathweftIndex, moves its settings and folder roots to ProgramData\Pathweft\services\file_index, and removes the old copy. The service name and its pipe are unchanged.
- Analyze space is offered by the command bar button only: the file, folder and background menus no longer carry "Analyze space in this folder".

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
