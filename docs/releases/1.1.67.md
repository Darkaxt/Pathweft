Pathweft 1.1.67 starts administrator access without UAC prompts, adds handle growth to System analysis, recovers from a stuck Everything, fixes copying downloaded files to drives without alternate streams, and shows loading progress in the space analyzer. (1.1.66 was not published; its changes are included here.)

- Administrator access: after one more approval, the installed Pathweft registers a hidden on-demand task and starts its administrator session through it, including at sign-in, with no further UAC prompt. Only the installed executable is accepted as the session; a failing task falls back to the one prompt. Settings › "Start administrator access with Pathweft" removes the task when turned off, and uninstall removes it (ACCESS-08, issue #7).
- System analysis › RAM: a Handle growth event (250,000 handles, or +100,000 within five minutes while growing), an optional Handles column, kernel paged/non-paged pool in RAM details, and a "parent ended" mark in process tables. A pinned process offers Handle types (read on demand) and End process, which asks first and rechecks the process identity. MCP get_top_processes and get_events report the same data (MONITOR-23, issue #5).
- Everything queries now give up after 45 seconds. Pathweft reports when Everything is loading or updating its index, and restarts a hung instance once per session, with its original options; the Everything service is never touched (SEARCH-05, issue #6).
- Copying to a destination without alternate data streams (FAT, exFAT, Tresorit Drive) leaves out only download marks (Zone.Identifier, SmartScreen), as Explorer does; any other alternate stream still refuses the file (TRANSFER-18).
- Space analysis shows a loading ring while an expanded folder is read, and lists its children before measuring unindexed subfolders (SPACE-09).
- Specification 1.24 records these.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
