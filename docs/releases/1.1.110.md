Pathweft 1.1.110 opens web pages in the browser again (CORE-37).

- Double-click and Enter on .html, .htm, .xhtml, .shtml and .svg files open them with their Windows association (your browser), as Explorer does, also with "Open code and text files in the Pathweft editor" on. F4 and Edit still open them in the editor; other code and text files still open in the editor.
- Help and What's new describe it.

Pathweft 1.1.109 updates to this release with the light package (`Pathweft-1.1.110-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
