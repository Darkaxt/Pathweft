Pathweft 1.1.47 corrects the package-manager Cleanup view introduced in 1.1.46.
Only installed managers with qualified cache actions appear. Chocolatey removes
expired user HTTP-cache entries; Npm, Pip and NuGet offer their reviewed native
cache actions. WinGet downloads, Cargo and vcpkg shared stores, PowerShell
modules, Windows Installer's managed cache and Bun's linked global store are
preserved.

NuGet HTTP cache now reports actual files and bytes instead of a present flag.
Pip and Npm report cache sizes, and results show measured bytes removed where
available. Pip discovers the installed Scoop Python when the app's process PATH
is stale. No cache is removed during analysis; Clean remains explicit and
rechecks the reviewed root and contents before the manager command runs.
