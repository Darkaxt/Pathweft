# Pathweft 1.1.13

Video and audio previews now use bundled libmpv with D3D11/gpu-next playback,
themed icon controls and Dolby Vision Profile 5/8 to SDR conversion derived from
the VLC and Nuvio forks. No separately installed player or Windows codecs are
required. The existing Video and audio module setting controls the integration.

Native Show in folder requests preserve file highlighting in Pathweft, including
inactive tabs. Existing Explorer navigation, opt-out restoration and virtual
folder behavior are preserved. Unlabeled drives now have consistent names in
the Folders tree and Drives list.

Qualification covers real SDR/audio playback, seek/EOF, Space autoplay,
selection/module/shutdown cleanup, source-bound DV P5/P8 reference comparisons,
and native 32/64-bit Shell selection. The Helium native boundary was replayed in
its actual running process against an invisible Pathweft fixture without desktop
input. Native Dolby Vision display signaling and full Profile 7 FEL are not
claimed. Pathweft binaries remain unsigned; verify the published SHA256SUMS.

The release includes installer, portable package, matching application sources,
dependency sources/build recipes, member manifest and checksums.
