Pathweft 1.1.78 replaces Everything with Pathweft's own file index for searches and folder sizes (S54).

- The Pathweft index service (native/pathweft-index, built in this release) reads each NTFS drive's file table once and follows its change journal, so searches answer in a fraction of a second even while many files change. Other drives, network shares and chosen folders are added as folder roots and rescanned every 6 hours.
- Searches, the taskbar search, folder sizes, the space analyzer, Scoop cleanup and the MCP tools ask the index service first. When it is not running, Everything answers as before. Search status names the index that answered; while a drive or folder is still being indexed, the result count says "index updating".
- Pane searches list only items you can open. The MCP search returns every match with a `visible` flag. Folder sizes count everything below the folder, including protected folders, so the space analyzer finds large protected caches.
- Settings → Windows integration → Pathweft index: service state, version and memory, each drive and folder root with its state and entries, Add folder…, Rescan, Remove, and Install service / Update service / Remove service through Pathweft's administrator session (Program Files installation only).
- The setup and portable packages include index\pathweft-indexd.exe and index\pwindex.exe. Installing or updating Pathweft does not install or restart the service; uninstalling Pathweft removes it.
- Date functions and dupe: are not supported by the Pathweft index; such searches say so.
- Specification 1.37 records this (SEARCH-06..08).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
