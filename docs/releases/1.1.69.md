Pathweft 1.1.69 lets read-only queries that Windows restricts to administrators use Pathweft's administrator access, in the app and in the MCP server.

- Boot diagnostics and Insights read the Diagnostics-Performance log through administrator access when it is running, instead of reporting it as unavailable.
- MCP (`Pathweft.exe --performance-mcp`): get_boots, get_insights, the Security check in get_maintenance, and list_folder on folders only administrators can list use administrator access.
  - The installed copy starts it through its on-demand task after your one approval in Settings, never with a prompt, and ends it when the MCP exits.
  - Without it (a portable copy, never approved, or turned off) these read as the signed-in user, as before, and say what could not be read.
  - The MCP still applies, cleans and uninstalls nothing (MCP-06).
- Fixed: Pathweft could crash on closing System analysis when Windows reported an empty path or command line for a process.
- Specification 1.26 records this.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
