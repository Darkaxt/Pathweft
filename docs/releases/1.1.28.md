# Pathweft 1.1.28

- Added a compact Performance command that swaps the lower summary cards for CPU, GPU, current physical-drive I/O and focused-folder I/O, with direct process/file detail tables.
- One shared in-memory rolling hour retains aggregate CPU, GPU and drive observations while Pathweft runs in the tray. Detailed file tracing requires explicit administrator permission and stops when its focused/visible scope ends; no collector service is installed.
- Removed the repeated capacity indicator beneath the address bar. Actual foreground folder/search loading appears within the address field without replacing its draft, focus or selection. Read-only archives use a centered diagonal corner ribbon.
- Added twelve ImageGen changelog illustrations, selected by release month rather than year.

Logical file requests, including cached I/O, differ from physical-device traffic.
Unavailable counters, unsupported virtual/network device mappings and incomplete
observations remain explicit. Existing file operations, previews and settings are
preserved. Summary-card transition animations remain a later stage.
