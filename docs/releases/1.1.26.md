Pathweft 1.1.26 expands the bundled native document previews and refreshes the
Word, spreadsheet and presentation cores. PhotoCraft/PSD/PSB, VectorCraft/SVG/
PDF-compatible AI and FigCraft documents gain read-only previews with native
artboard or frame navigation. Existing Figma thumbnails retain priority.

Windows PDF remains the default; Craft PDF is an optional renderer. All seven
cores provide bounded text extraction with native locations for later indexing.
This release does not activate indexing or OCR. Legacy PostScript AI/EPS and
uninterpreted document features are reported explicitly. LibreOffice remains
the single-attempt Office recovery path.

The existing folder-and-compass icon has a larger visible footprint. Windows
application identity, shortcuts, pins, storage settings and profiles are preserved.

Windows x64 installer and portable packages are supplied with checksums and
complete application/dependency sources. Pathweft binaries remain unsigned.
