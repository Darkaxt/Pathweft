Pathweft 1.1.113 adds Pathweft's own Start menu beside StartAllBack (S6a, S6b: SAB-02, SAB-03, SAB-04, SAB-06).

- Settings → Windows integration → Keyboard → "Win, Ctrl+Esc and the Start button open Pathweft's Start menu" (off by default). With it on, a lone Win, Ctrl+Esc and StartAllBack's Start button open Pathweft's menu at the Start button; Esc or Win again closes it. Turning it off, or the helper ending, brings StartAllBack's menu back.
- Left column: pinned programs, then the programs you start most, as many as StartAllBack is set to show; jump lists beside programs; All Programs with your Start menu folders and Windows apps, beside the menu or in place as StartAllBack sets it, with newly installed programs highlighted.
- Right column: your picture, folders, Computer, Control Panel, PC settings and StartAllBack's other commands in its order, with cascading menus. Folders, drives and Computer open in Pathweft.
- Search: Programs and Settings at once, then Folders, Documents, Pictures, Music, Videos and Files from Pathweft's index with their counts; Enter opens the first result; See more results opens a This PC tab searching the index.
- Right-click a program for Open, Run as administrator, Open file location, Pin to or Unpin from Start menu, Remove from this list and Properties. Shut down, with Restart, Sleep, Hibernate, Sign out, Lock and Switch user beside it.
- Help and What's new describe it.

Verified in an isolated Windows Sandbox guest with StartAllBack's taskbar (docs/verification/2026-11-27-s6a-guest.md, docs/verification/2026-11-27-s6b-guest.md). StartAllBack's layout and visual style settings follow in later releases.

Pathweft 1.1.112 updates to this release with the light package (`Pathweft-1.1.113-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
