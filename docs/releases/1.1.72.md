Pathweft 1.1.72 makes its right-click menu one organized menu (S49).

- Other apps' commands: what programs and Windows add to the Explorer menu for the selection (Open with Code, Git Bash here, Play with VLC, Scan with Microsoft Defender, PowerToys, Pin to Start and others) now appears in Pathweft's menu, in its groups: commands that open the items in a program sit beside Open (or in Tools on a folder's background), the rest under More actions. A command that repeats one Pathweft already has is left out.
- Ctrl+right-click opens the other menu: the standard Windows menu when Pathweft's is the default, Pathweft's when Settings → Files → Context menu is set to Windows. From the keyboard: Ctrl+Shift+F10 or Ctrl+Menu key. It works in the search widget too. The separate "Windows menu…" item is gone.
- Removed: the links to the upstream sister apps (Backup Labs, Reel, Shelf, Stash, Lume), their menu items, previews and help rows, and the "Works with other apps" section. Pathweft's old Pin to Lume list (lume.txt) is deleted; files other apps wrote are left alone.
- Specification 1.30 records this (S49, MENU-05..09).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
