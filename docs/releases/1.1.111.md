Pathweft 1.1.111 keeps searches from coming up empty (CORE-38).

- When a batch of index results holds only hidden items (for example a path search in a folder with a .git folder, whose objects sort first), the pane loads the next batch by itself until visible results arrive or the results end, instead of showing an empty list with More results. This applies to the first batch, to More results and to widgets. Hidden items stay hidden unless Show hidden is on.
- Help and What's new describe it.

Pathweft 1.1.110 updates to this release with the light package (`Pathweft-1.1.111-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
