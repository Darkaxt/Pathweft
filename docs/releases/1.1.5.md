# Pathweft 1.1.5

- Free-space values in This PC include the rounded percentage available. Usage
  bars share warning colors with the sidebar: the selected accent below 80%
  used, amber from 80%, and red from 90%.
- Empty card-reader slots and other unavailable drives stay hidden until media
  becomes available.
- Google Drive mounts and Tresorit's registered network endpoints display Cloud
  and their provider instead of a misleading physical filesystem label. The raw
  reported filesystem remains in the drive tooltip.
- Model and PDF preview actions use icons with tooltips and accessible names.
  The animation selector follows the app theme. F3D renders transparent frames,
  removing the contrasting black rectangle around models.
- Executable previews show available file/version/product/company details,
  architecture, size, dates and location without running the application.
- Native folders and virtual folders inside supported archives share the themed
  expandable tree. Native branches load when expanded. The preview pane collapses
  when nothing is selected and returns at its saved width on the next selection.

Windows 11 x64, self-contained .NET 10. Application and installer are unsigned.
Includes installer, portable package, corresponding application/dependency
sources, release manifest and SHA-256 checksums.
