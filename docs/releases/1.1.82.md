Pathweft 1.1.82 puts the integrated file tools on the folder's own menu (TOOLS-11) and makes indexed folder sizes wait for recent writes (SEARCH-10).

- Right-click a folder's empty space → Tools: Rename all… renames everything the folder shows (with the preview, options and Undo of the selection's Rename all…), Resize images… resizes the pictures it holds, and What's using this? lists the programs holding the folder or anything in it.
- PowerToys' own Rename with PowerRename, File Locksmith and Image Resizer entries are no longer repeated under More actions: Pathweft offers each of those tools once, under its own name.
- Space analysis and folder-size rows measure a folder written in the last two seconds instead of taking the index's size, so a file written just before they run is counted.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
