# Pathweft 1.1.14

Updates now show measured download progress and a compact deployment popup that
matches Pathweft's updater UI. It remains available after the app closes and
reports file installation, integration restoration and reopening. Light/dark
mode and the current accent carry through; installation failures remain visible.
Existing 1.1.13 clients receive the deployment popup when installing this release.

Clicking video and animated 3D timelines now seeks immediately while playing or
paused. Playback continues from the selected time, with thumb dragging and
keyboard controls preserved.

Qualification covers real libmpv/F3D seeking, download/checksum/cancellation,
hidden WPF and native installer layouts, real installer progress and failure
callbacks, and the delivered native Shell and application workflows.

The release contains installer, portable application, matching application and
dependency sources, release manifest and SHA-256 checksums. Pathweft's binaries
and installer are unsigned; the manifest records the exact source and file hashes.
