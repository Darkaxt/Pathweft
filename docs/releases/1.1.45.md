Scoop Cleanup can now remove obsolete versions containing ReadOnly junctions
into Scoop's persistent-data directory. Pathweft clears ReadOnly on the junction
name before unlinking it; the persistent target and its contents stay unchanged.

This corrects the access-denied failures reported for older 7-Zip, MEGAcmd,
mpv-git, MSYS2, Python and yt-dlp versions in 1.1.44. Cleanup still starts
deletion directly, protects the current version and reports genuine file locks
or access failures as incomplete rather than claiming removal.
