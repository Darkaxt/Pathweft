Pathweft 1.1.97 makes Analyze space read from the index without timed disk fallbacks (CORE-32) and reports an update that could not be installed (UPDATE-04).

- Analyze space takes every folder the Pathweft index service covers from the index, in standard and administrator view, on opening, F5 and view switches. A folder written a moment ago is asked for once the index has read the change journal past it (600 ms after its newest write) instead of being measured on disk. While the service is still loading the drive, the analysis waits for it with no time limit and the footer says so; Ctrl+R stops the wait and measures on disk. Folders the index does not cover are measured on disk; if the service is absent or fails, the footer says why. Pane folder sizes are unchanged.
- The updater runs setup with a log (kept in Pathweft's updates folder) and records the version it started. An update that could not finish reopens Pathweft, which opens the update window with the version, setup's reason and the end of its log, Open log and Try again. This applies to updates started from 1.1.97 on.
- Help (F1) and What's new describe both.

Pathweft 1.1.96 updates to this release with the light package (`Pathweft-1.1.97-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
