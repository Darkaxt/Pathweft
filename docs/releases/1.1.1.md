# Pathweft 1.1.1

The application now uses a transparent yellow-folder icon with contrasting
two-pane list marks, sized to read like a native Windows folder. The pink tile
is removed across the application, executable, shortcuts and installer.
Sidebar content now fades softly at clipped scrolling edges. The title, footer
buttons and scrollbar stay sharp; the fade disappears when the content fits
and is disabled in high contrast.

Native windows now use the Windows accent on their active outer border when
Windows enables colored title bars and window borders. Inactive windows restore
the system frame color, Native caption surfaces stay neutral, and changes to the
Windows color preference refresh existing windows. This follows Windows' frame
accent independently of the application's custom selection color.
Native windows use Windows' closing transition instead of fading their client
content into an empty colorized rectangle before the window disappears.
Closing also releases folder watchers and their pending refresh timers before
window resources are torn down.

Each pane now has one browser-style address/search field in the path row.
Enter resolves an existing path first, then falls back to Everything. The current
folder scopes the search; This PC searches the full index. The separate search
row, scope picker, funnel and search icon are removed. Four inline switches
provide Match case, Match whole word, Match path and Regex, including handoff
from taskbar search. The Native dark outer background matches the sidebar.

Settings now starts with Appearance instead of a large indexed-search report.
Search instructions and scope/compatibility details are available through Help;
startup and profile details are collapsed under Diagnostics. Integration options
retain concise actionable status and limitations.

Automatic opening now falls through to the normal Windows application when the
internal editor cannot read a file, including oversized or binary HTML. It no
longer shows an editor error or opens an empty editor for these files. This also
applies to extracted archive files. F4/Edit remains an explicit edit command.

The Original theme remains available. Folder routing and Win+E remain opt-in;
existing settings and registrations are preserved. Context-menu reorganization
is planned as S9, not implemented in this update. StartAllBack and the broader
Windows Search migration remain postponed S6/S7 work.

Windows 11 x64, self-contained .NET10. Executable and installer remain unsigned.
Installer, portable ZIP, matching application and dependency sources, manifest
and SHA-256 checksums are included. See the packaged usage and third-party notices
for existing integration and archive-format limits.
