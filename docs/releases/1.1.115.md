Pathweft 1.1.115: the Start menu keeps correct behaviour where StartAllBack's menu gets it wrong (S83: SAB-08, issue #15).

- A jump-list arrow shows only beside programs whose jump list has something in it; an empty jump list no longer gets an arrow.
- Recent programs stay ranked by how much you really use them, and All Programs stays highlighted while it holds a newly installed program you haven't opened, where StartAllBack's own menu does otherwise (the owner's decision).
- Help and What's new describe it.
