Pathweft 1.1.59 starts on every PC and quotes copied paths.

- Fixed: a fresh install on a PC without a D: drive closed at startup, and Setup reported that the Win+E helper could not restart. Since 1.1.11 Pathweft's bulk data (caches, undo journal, editor profile, activity store, runtime temp) defaulted to D:. A first start now uses an existing D:\AppData\Pathweft folder, else the first ready fixed non-system drive, else %LOCALAPPDATA%\Pathweft only when Windows' drive is the sole local drive, and records the choice in data-root.txt so it never drifts. A chosen drive that is missing is reported in a message. Existing installs keep their location.
- Copy path (menus and Ctrl+Shift+C, in panes and the search widget) quotes each path, one per line, as Explorer's Copy as path does.
- The address bar already accepted quoted paths; pasting a copied file path opens its folder with the file selected, now covered by a test.
- While hidden files are concealed, a folder or archive footer adds "· N hidden".

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
