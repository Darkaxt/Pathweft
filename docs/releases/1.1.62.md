Pathweft 1.1.62 makes the administrator approval given at launch the only one.

- Maintenance now uses the administrator session approved when Pathweft starts instead of opening its own, and keeps it until Pathweft exits. Elevated Windows tweaks, services, all-users startup items, protected Cleanup review, restore points and administrator leftovers no longer show another UAC prompt.
- Desktop programs and Chocolatey packages are uninstalled through that session, so their uninstallers inherit it rather than requesting elevation again. Store apps and Scoop packages are still removed for the current user only.
- A request is made only when no session exists (the launch request was declined or turned off in Settings); its approval then lasts until Pathweft exits. The administrator shield still only switches Explorer browsing, and "Run as administrator" on a file is unchanged.
- The Maintenance details panel keeps its title and close button fixed while only the text scrolls, and protected rows explain why once.
- Specification 1.19 records this as ACCESS-07, superseding Maintenance's separate session (MAINT-23) and the unelevated uninstaller launch (MAINT-34).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
