Cleanup analysis keeps its results selectable while it scans. You can inspect
details, sort or filter the table, switch to another loaded Maintenance category,
or return to files without waiting for the whole queue to finish.

Scoop analysis and cleanup now observe cancellation throughout package traversal
and between native resource-registration batches. Cancelling preserves
unprocessed files and releases the original operation's directory handles.
The active category shows Analyzing while its review is running.

The hidden-files eye belongs to the file browser. It is hidden in Maintenance
and expanded Performance analysis, and restored with its existing state when
you return to files.
