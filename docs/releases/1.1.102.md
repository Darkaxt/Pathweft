Pathweft 1.1.102 fixes clicks that turned into drags (CORE-33).

- A click or double-click on a file while the preview panel opens no longer starts a drag: the drag distance is measured from where the mouse was pressed on the screen, not within the file list, which the preview panel resizes. The second press of a double-click never starts a drag.
- Moving items into the folder they are already in does nothing, as in Explorer, instead of opening a failed Transfers card. Ctrl+drop into the same folder still makes a copy beside the original.
- What's new describes it.
