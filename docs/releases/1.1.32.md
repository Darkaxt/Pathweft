Expanded performance analysis now includes an interactive timeline adapted from
SysOptimizer: grouped event and spike markers, hover details, pinned moments,
range selection, zoom, pan and an overview navigator. Selecting a moment shows
the nearby recorded app observations; selecting a range scopes the linked facts.
Keyboard navigation and Now return to the current view.

The compact widgets keep their existing layout. Analysis follows Pathweft's
themes and fits narrow windows and larger text, with scrolling when needed.
Missing observations remain gaps. History recording remains optional, and this
release adds no background collector or MCP activation.
