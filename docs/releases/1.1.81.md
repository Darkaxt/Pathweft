Pathweft 1.1.81 adds browsing productivity and smart destinations (S21, BROWSE-01..12) and the Performance window changes (MONITOR-25).

- Address bar suggestions: one ranked list from both panes' open tabs, every Quick access list, saved searches, recent folders and path completion, with the matching text highlighted and where each one comes from. Up/Down choose, Tab completes, Enter opens, Escape closes and keeps what you typed. A history entry can be removed from the list; Settings → Privacy → Clear history clears recent folders and closed tabs.
- Saved searches: Save this search keeps the query, folder and options; they appear in the sidebar and in suggestions.
- Custom actions: your own commands under right-click → Actions, filtered by file pattern, files/folders and selection count, with %f %F %n %N %d placeholders quoted by the Windows rules. Edit them in Settings → Actions or in actions.json (docs/CUSTOM-ACTIONS.md). An action runs only when clicked.
- Folder view profiles: View → Folder view saves a folder's view mode, sorting and columns, optionally for its subfolders.
- Synchronize with other pane: compare by date and size or contents, including subfolders; each row shows the proposed direction, which you can change or skip, before anything runs. Replaced files go to the Recycle Bin and the operation can be undone.
- Tags, rating and comment: stored by Pathweft per file (they follow renames and moves on the same volume), shown as columns and searchable in the filter with tag:, rating: and comment:. Settings → Privacy lists notes whose files are gone and can forget them.
- Terminal panel: View → Terminal panel or Ctrl+Shift+` opens a terminal under the pane. It follows the folder you browse, and the pane follows the shell's cd. Ctrl+` still opens your external terminal. Window shortcuts stay out of a focused terminal.
- Remote folders: SFTP (SSH.NET) and WebDAV connections in the sidebar, with passwords in Windows Credential Manager and host keys confirmed on first connect. Copy, move, rename, delete and new folder, with a transfer window, one conflict question and cancellation. Previews use a temporary copy up to 64 MB.
- Filter: View → Filter or Ctrl+Shift+F filters the current folder as you type.
- Links: create symbolic links, hard links and junctions; a Link target column; Properties of a link shows its kind and target, and whether it is broken, with Windows Properties one click away.
- Performance: the process filter moved to the top centre and filters both the graph and the table; Pause stops refreshing so you can look at one moment.
- Packages add SSH.NET, the Windows Terminal control and ConPTY, with their notices under licenses\Remote and licenses\Terminal.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
