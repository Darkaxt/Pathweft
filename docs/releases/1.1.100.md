Pathweft 1.1.100 lowers the cost of the live analysis while a UI Automation client (screen readers, text and capture tools) watches the window (MONITOR-27, issue #13).

- The live CPU and RAM process tables reuse their row containers when processes change places, instead of building new rows, keep only the visible rows built, and update only the values that changed in a sample, so a listening client receives far fewer structure and name changes. Selection and pins still follow the process.
- What's new describes it.

Pathweft 1.1.99 updates to this release with the light package (`Pathweft-1.1.100-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
