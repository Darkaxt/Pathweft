# Pathweft 1.1.24

- Transfer review shows files with different sizes or modification dates, with only differing properties displayed. Newer destination files appear first in orange with a text warning. Show matching files reveals the rest; every choice still applies to all conflicts.
- PiP and floating previews now follow file selection. Use the new pin button to keep an item; unpinning immediately follows the current selection. Smaller header icons retain their original click targets.
- Updated the application icon to a yellow folder and bronze compass, with transparent Windows size variants. Existing shortcuts, taskbar pins and application identity remain unchanged.
