Pathweft 1.1.87 adds light updates (S59: LIGHT-01..04), Undo that follows the tab and Help for the recent features.

- Each release now also publishes `Pathweft-<version>-update.exe` and its description `Pathweft-<version>-update.json`: only the files that changed since the previous release, the files to remove and the new release-manifest.json.
- Before downloading, the updater checks that the installed version is the light package's base, that the installed release-manifest.json is the base's and that every file it lists is unchanged. Otherwise it downloads the full installer, and the update window says why. The check shows its progress and can be cancelled.
- The light update checks the installed files again before changing anything. If one differs, it changes nothing and Pathweft reopens to install the full update. After installing it checks the files it wrote.
- The full installer is unchanged and stays the package for new installations; portable copies update as before.
- Undo follows the tab (UNDO-01): Ctrl+Z and the folder menu's Undo take back the latest operation that touched the active tab's folder. Operations in other folders are not offered there; History → Operation history… still undoes any of them.
- Help (HELP-01) has entries for every feature since 1.1.82: Index contents and content: search, workspaces, linked panes, collections, path aliases, expandable folders and flat view, Copy as table and Export listing, operation history, image marks, light updates and the tab-scoped Undo.

Pathweft 1.1.86 and earlier download this release whole; the first light update is the one after 1.1.87.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
