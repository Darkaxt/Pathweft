Pathweft 1.1.75 keeps a space analysis with its tab and shows deletions in it at once (S49H).

- Clicking the tab on screen changes nothing, as in Explorer. Before, it left the space analysis and showed the folder listing.
- Switching to another tab, opening a new one, closing or moving other tabs keeps the analysis with its tab. It keeps measuring in the background (folder sizing waits for it), and the tab comes back with the same tree, expanded folders, selection and scroll, without measuring again. Closing the tab ends it. Changes made while it is in the background are picked up with F5.
- Delete, Shift+Delete and the menu's Delete on an analysis row remove it, and its size, files and folders from every folder above it, as soon as the delete finishes. The row that moves into its place is selected, so Delete can be pressed again. That branch is then re-measured quietly. Before, the deleted row stayed until a full re-measurement, so deleting it again did nothing.
- Specification 1.34 records this (SPACE-11).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
