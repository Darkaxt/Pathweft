Pathweft 1.1.103 updates its RAR library to rars 0.13.0 (RAR-06).

- The embedded RAR library is rars 0.13.0 (`f7098c7`), with upstream fixes to reading the end of members and archives, split-volume boundaries, RAR 2.9-4 writing and RAR 5 decoding. Pathweft's RAR browsing, creation, editing, recovery records, passwords and volumes behave as before; they were qualified against the RAR contracts (including the Compress... RAR settings) and official UnRAR before the update.
- Truncated or damaged RAR archives are refused for editing and kept byte for byte.
- The source package's Rust sources are vendored from the new lock file.
- What's new describes it.

Pathweft 1.1.102 updates to this release with the light package (`Pathweft-1.1.103-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
