# Pathweft 1.1.0

The first core file-manager release combines pane and taskbar Everything search,
internal selectable previews, native archives and one shared transfer queue.

- Original and Native appearances, Windows light/dark/accent support, and shared
  widget/editor styling. Ctrl+P switches single/split panes; Ctrl+H toggles hidden
  attributes and dot-name files. Read-only files use gray icons with lock cues.
- Eight internal preview modules, including the opt-in F3D GLB prototype, without
  a standalone QuickLook installation.
- Native ZIP/7z/TAR editing and eligible RAR reading/editing, with variant-specific
  preservation limits. No installed archive application is required.
- The internal REA-informed transfer engine, direct-write cancellation cleanup
  and optional verification. No TeraCopy binary is launched.
- Reversible opt-in filesystem-folder registration and independent Win+E under
  Settings > Windows integration. The installer leaves integration off.
- Selected upstream filter, inclusive size-query and rename rollback fixes; .NET
  10 self-contained delivery and per-user install/update/uninstall.

Windows 11 x64 is qualified. WebView2 Evergreen is required for the optional F4
editor. Everything search uses the existing default instance; the bundled pinned
engine is never started or configured automatically.

StartAllBack search and its Shell/known-folder/library links, plus the broader
Windows Search/Outlook indexing migration, remain postponed S6/S7 work. Windows
Search configuration is unchanged. Explicit Explorer launches, virtual locations
and common file dialogs remain Windows surfaces. Direct
`SHOpenFolderAndSelectItems` is unsupported: enabling folder routing can open the
folder without the requested selection and return `E_ABORT`. Keep folder routing
off if callers relying on that behavior are essential; Pathweft's own `/select`
command is supported.

The Pathweft executable and installer are unsigned. The release includes the x64
installer, portable ZIP, matching application/dependency sources, a per-file
source/version manifest and SHA-256 checksums. Original dependency terms and
notices are retained; the combined QuickLook-derived application is
GPL-3.0-or-later. See the packaged usage and third-party notices for exact limits.
