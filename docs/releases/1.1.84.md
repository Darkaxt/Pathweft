Pathweft 1.1.84 adds content search for folders you choose (S19, CONTENT-01..06, spec 1.45), with the index service's content store (IS10, protocol 2).

- Index contents on the command bar adds the folder shown and its subfolders to the index service's content index. Pathweft's content worker runs below normal priority inside a memory-capped job, reads text, logs, JSON/JSONL and the documents its Craft cores open (Word, PDF and the others), and sends 64 KiB chunks with their locations; unsupported and binary files are marked not indexable, and cloud placeholders are never downloaded. Changed files are re-read on the service's next check.
- content:word, content:"phrase" and content:prefix* combine with every other query filter. Results show where the word was found (near line N, page N, paragraph N); right-click → Open at line opens a text match in the editor at the exact line.
- Files in an indexed folder carry a content badge and tooltip; Settings → Windows integration → Pathweft index lists the indexed folders with indexed, waiting and not-indexable counts and the store size. Pressing Index contents again removes that folder's content index; files are unchanged. With an index service older than protocol 2 the button and the Settings section are hidden.
- The index service keeps the content store in ProgramData\Pathweft\services\file_index\content, readable only by SYSTEM and Administrators, using SQLite 3.54.1 (public domain) through rusqlite.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
