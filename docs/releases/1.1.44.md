Scoop Cleanup now starts native deletion of reviewed obsolete version folders
without a package-use preflight. It does not register package files with Windows
Restart Manager. This removes the measured 23-second wait before deletion on the
host's 18 reviewed candidate folders.

Windows may refuse a locked file after other members of that obsolete version
have been removed. Pathweft reports the version as skipped and incomplete, with
the native error; it never counts a partially removed folder as cleaned. Current
version bindings and external persistent data remain protected. Cancellation
finishes a version already being deleted and stops before the next one.
