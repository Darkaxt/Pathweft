Pathweft 1.1.65 lets you run PowerShell scripts from the context menu.

- Right-clicking a single .ps1 file offers Run with PowerShell, and Run as administrator under Tools. Both run `pwsh -NoProfile -File` on the script in its own console, starting in the script's folder; without PowerShell 7, Windows PowerShell runs it with a RemoteSigned policy for that run only. Run as administrator asks for Windows administrator consent.
- Opening a script still edits it, as in Windows.
- Specification 1.22 records this as MENU-04.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
