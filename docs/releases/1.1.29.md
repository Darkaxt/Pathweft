# Pathweft 1.1.29

- Merged thirteen File Labs upstream commits through `8ceb281`, preserving Pathweft's native integrations, verified transfer engine, previews, unified search, storage policy and monthly artwork.
- Persisted Undo history and interrupted-transfer recovery. Folder Undo affects recorded arrivals only, preserving later additions, changed files and occupied original locations. Native recycling records the exact deleted Windows item for restoration.
- Added durable batch-rename recovery, partial-transfer Undo, scoped multi-folder move confirmation and virtualized large Drop bin selections.
- Added Segoe MDL2 icon fallback for Windows 10 while keeping compact themed controls.

Code-scanning alert 1 was assessed against the shipped Monaco embedding and
dismissed as a false positive. Its optional worker-script path is app-owned,
unset and unreachable from opened documents or sandboxed Markdown. The scanning
rule remains enabled.

Upstream promotions and alternative transfer/search implementations were omitted
where Pathweft already supplies its established behavior. See the integration
record for the exact adoption decisions and verification limits.
