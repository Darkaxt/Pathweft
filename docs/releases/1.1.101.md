Pathweft 1.1.101 adds eBook previews (EBOOK-01), fixes mapped network drives in administrator view (ACCESS-09), and makes the MCP's pages say where they continue (MCP-09).

- eBooks: EPUB 2 and 3, FB2, MOBI, AZW3 (KF8), AZW and PRC open in the preview as native pages, with the cover, title, author and details on top, a Contents picker, and the PDF viewer's page controls. Paging continues across chapters, links inside the book work, and DRM-protected books show only their details and cover. MOBI/KF8 reading is adapted from calibre (GPL-3.0, vendor/Calibre). LIT is not supported.
- Administrator view: network shares and mapped network letters are always read with standard access, because the elevated session has no mapped letters and administrator rights grant nothing on a share. The access-denied prompt on a share says so instead of offering administrator access.
- MCP: every paged tool, search_files included, returns `status`, `rows`, `total`, `offset`, `limit`, `returned`, `has_more` and `next_offset`. The status names the next offset or says it is the last page. Paged tools other than search_files now use these lowercase field names instead of `Status`, `Rows`, `Total`, `Offset` and `Truncated`.
- Help and What's new describe the changes.

Pathweft 1.1.100 updates to this release with the light package (`Pathweft-1.1.101-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
