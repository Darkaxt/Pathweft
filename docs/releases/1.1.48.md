Pathweft 1.1.48 makes Maintenance refresh itself. Opening Maintenance reviews
Cleanup and reads the five category summaries. Selecting a card immediately shows
its cached rows; returning to a card refreshes its Windows state in the
background. Cleanup is reviewed again after an action. Manual Refresh and
generic Analyze buttons are gone. An already approved administrator session can
update protected reviews without a new prompt on ordinary entry.

Cleanup's Details column now uses concise descriptions. Cache paths, unavailable
entry counts and review examples remain in the selected assessment so a failed
or partial review can still be understood. Recommendation is shown only for
Windows tweaks, which have a reviewed rule for every displayed setting. Startup,
Services and Windows apps continue to show their real state and any exact matched
guidance in the selected assessment, without a mostly empty recommendation column.

The inactive Performance and standard-access administrator icons recede while
Maintenance is open. Both controls remain usable; administrator access still
supports protected Cleanup reviews. Active administrator access remains visibly
marked, and the toolbar returns to normal emphasis on leaving Maintenance.

Clean remains explicit and rechecks its exact review before removal. No installed
package, startup entry, service, tweak or app is changed by automatic refresh.
