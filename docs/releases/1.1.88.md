Pathweft 1.1.88 adds command lines to the app activity recorder (ACTIVITY-07) and is the first release delivered as a light update.

- Record app activity keeps each run's command line, from the kernel's process start events so short processes are included, and the folder the program started in.
- Passwords, tokens, API keys, bearer values and credentials in URLs are masked before saving. Command lines are capped at 2,048 characters with their original length noted; each distinct text is stored once.
- MCP `get_run_history` returns `command_line` and `working_directory`, and its `name` filter also matches the command line; `get_workloads` returns `root_command_line`. Runs recorded by 1.1.87 and earlier show the path only.
- The activity store limit rises from 128 MiB to 1 GiB. A full store now trims the oldest history and retries the batch instead of dropping it.
- Pathweft 1.1.87 updates to this release with the light package (`Pathweft-1.1.88-update.exe`); earlier versions download the full installer.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
