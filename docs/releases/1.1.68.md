Pathweft 1.1.68 extends its read-only MCP server to Maintenance, files, Everything search and Windows boots and changes. It also moves the process table's controls onto the table and fixes Office preview closing with a locked temporary file.

- MCP: `--performance-mcp` (now named Pathweft) adds nine read-only tools: get_maintenance, get_maintenance_changes, list_folder, get_file_details, get_folder_size, search_files, get_boots, get_system_changes and get_insights.
  - get_maintenance returns the Maintenance rows. Cleanup sizes come from Everything's index where possible, and each row states how its size was found.
  - search_files accepts the full Everything syntax, with path, case, whole-word and regex switches, six sort orders and paging.
  - Nothing is applied, cleaned, uninstalled or elevated, file contents are never read, and the MCP never restarts Everything.
  - Closing stdin ends a running request (MCP-01..05).
- System analysis process table:
  - The process filter, Handle types, End process and a compact Columns button sit on a bar directly above the table.
  - Right-clicking the header row opens the column chooser.
  - CPU and RAM keep separate column choices, saved across restarts.
  - The footer only appears for a history recording problem (MONITOR-24).
- Office preview: closing no longer fails when another program briefly holds a LibreOffice temporary file. The leftover folder is removed when a later preview closes (PREVIEW-39, issue #4).
- Specification 1.25 records these.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
