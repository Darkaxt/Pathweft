Pathweft 1.1.57 makes the administrator shield manage file browsing only.

- The shield switches file browsing between standard and administrator access and nothing else. It is disabled in the Performance panels, as it already was in Maintenance.
- Performance's detailed disk activity and drive health use the administrator access granted when Pathweft starts (or their own Enable actions); toggling the shield no longer affects them.
- The shield's "End administrator session" menu was removed, because it also ended Performance's elevated work. The administrator session ends when Pathweft exits.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
