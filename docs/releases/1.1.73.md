Pathweft 1.1.73 follows up 1.1.72's organized menu and makes update checks quiet (S49F).

- Open with: every command another program adds to open, play or edit the selection (Open with Code, Open Git GUI/Bash here, Play with VLC and others) is now in one Open with submenu, after Windows' own Open with list, on files, folders and a folder's empty space.
- Menu icons: Pathweft's icons and other programs' icons share one slot, so they line up.
- Archive: Compress to 7z, beside ZIP and RAR, on disk and inside archives.
- Updates: when the hourly check finds a new version, the update button at the top of the sidebar shows a dot instead of opening a window. Clicking it shows the release and Update now; checking by hand works as before.
- Specification 1.32 records this (MENU-10, ARCHIVE-11, UPDATE-03).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
