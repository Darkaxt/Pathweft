# Pathweft 1.1.12

- Cover the explicit Windows Folder/explore route used by Chromium/Helium's
  Open downloads folder action through the existing opt-in folder handler.
- Extend intact enabled registrations during updates. Turning integration off
  restores the previous Folder command and delegate, including value types.
- Preserve navigation within Explorer, virtual folders and later changes made
  by another file manager. The direct Show in folder selection API remains a
  separate documented limitation.

Verification covers registration upgrades/restoration, the exact shipping
Folder/explore mapping, hidden32/64-bit native browser-site navigation and
delivered-package checks. The final live Helium action is checked by the user.
