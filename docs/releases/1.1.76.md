Pathweft 1.1.76 brings selected PowerToys file tools into Pathweft and completes the Archive menu (S20).

- Rename all uses PowerRename's engine and options: regular expressions or plain text, match case, every occurrence, ${} enumeration, name or extension only, case changes, files or folders, and creation/modification/access date tokens. The preview shows every new name and blocks invalid or colliding names; Undo works as before. EXIF/XMP tokens are not included.
- What's using this? (File Locksmith) lists the processes holding the selected files or folders open, with their program and paths, and Refresh. A copy, move or delete that fails because a file is in use offers the same from the Transfers card. Without administrator rights, processes of other users and elevated processes may not be visible; Pathweft says so. It does not end processes or close handles.
- Resize images… (Image Resizer): presets or custom sizes in pixels, percent, centimetres or inches; fit, fill or stretch; shrink only; JPEG quality, PNG interlacing and TIFF compression; metadata removal; beside the originals, in another folder or replacing them (originals to the Recycle Bin). It runs as a Transfers job with cancel and Undo.
- Text in pictures (Text Extractor): the preview's text button recognises text in a selected area or the whole picture with Windows' OCR, in the languages installed on this PC, and copies it. Recognition uses the preview image (up to 2000 pixels on its long side).
- .reg files preview as a key/value tree with value types and data, and the source text; nothing is written to the registry.
- Paste as file (Advanced Paste, without AI): the clipboard's text, HTML or picture becomes a new .txt, .html or .png file in the folder, ready to rename; Ctrl+Z removes it.
- New from template (New+): files and folders from a templates folder you choose, in New file, New folder and the right-click New group, with optional name variables such as $YYYY and %USERNAME%.
- Archive: Open archive, Extract files… (choose the folder), Extract here, Extract to "name\", Test archive, Compress to ZIP / 7z and email (your default mail program's new message, with the archive attached), and Checksum: CRC-32, CRC-64, MD5, SHA-1, SHA-256, SHA-384, SHA-512, SHA3-256, XXH64, XXH3-64 or all of them, for files, folders and files inside archives. NanaZip's own command is left out of Pathweft's menus; Windows' menu (Ctrl+right-click) still has it. NanaZip's rarer hashes (GOST, Whirlpool, EDON-R and others) are not included.
- Every Archive command has an icon, and Compress… uses two columns, without scrolling.
- The PowerToys code is adapted from microsoft/PowerToys 2d817b0 (MIT); its notices ship in vendor/PowerToys. No PowerToys runner, settings, shell extension or telemetry is installed.
- Specification 1.35 records this (TOOLS-01..10, ARCHIVE-13, ARCHIVE-14).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
