Pathweft 1.1.116: the Start menu looks like StartAllBack's, with its Visual style, transparency and light or dark mode (S6d: SAB-07, visual styles).

- Pathweft's Start menu takes StartAllBack's Visual style: Default's rounded panel, or the Windows 7, Plain8 or another installed style, drawn from the style file StartAllBack has installed (none of its images ship with Pathweft).
- It is see-through over a blur of the desktop as StartAllBack's Transparency and Blur are set, light or dark with Windows' mode, and follows a change at once.
- Searching fills the whole menu with the results, the first one highlighted for Enter; See more results takes All Programs' place and the search box has a clear button.
- Pointing at a folder in the right column shows its icon where your picture is.
- Help and What's new describe it.

Pathweft 1.1.115 updates to this release with the light package (`Pathweft-1.1.116-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
