Pathweft 1.1.80 replaces Everything with the Pathweft index service (S56, SEARCH-09).

- Pane search, the Ctrl+Alt+Space popup, folder sizes, the space analyzer, Scoop cleanup and the MCP server use only the Pathweft index service. The Everything client, SDK, bundled engine, its monitor and named-instance support are removed; the packages no longer contain Everything.
- Pathweft never stops, changes or uninstalls an Everything installation of your own; it just no longer uses it.
- Setup installs or updates the index service silently after each install or update. Uninstall removes the service and keeps its folder-root settings. Settings → Windows integration → Pathweft index keeps Install, Update and Remove as repair.
- When the service is not running, searches say so and folder sizes are measured on disk. Pane rows and the space analyzer wait at most 5 seconds for the index before measuring.
- The index service adds dm:/datemodified: and dc:/datecreated: (today, thisweek, lastmonth, years, dates, ranges a..b and comparisons) and parent: for a folder's direct children.
- Folder roots (FAT32, cloud folders, network shares) are rechecked adaptively, every 15 minutes to 6 hours per folder, which catches changes that send no notification.
- Fixed in the index service: a folder created while the service was running could report a deleted file's size as its own, inflating it and every folder above it (an empty new folder showed 17,704 bytes). Totals are correct again once Setup has updated the service.
- An invalid reply from the index service no longer closes Pathweft; the folder is measured on disk instead.
- Specification 1.39 records this (SEARCH-09).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
