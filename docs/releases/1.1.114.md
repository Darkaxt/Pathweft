Pathweft 1.1.114: Pathweft's Start menu follows StartAllBack's layout and contents settings (S6c: SAB-01, SAB-07).

- The power button does what StartAllBack's "Power button default action" says (or the Start-menu power button policy), such as Hibernate, with its glyph.
- Icon size (S, M, L) and the "Use large icons" boxes for All Programs, search and the right column's menus set the menu's icons.
- All Programs sorts as StartAllBack's "Override sort order" says: folders first, programs first or both together.
- The right column shows StartAllBack's glyph icons and the user picture as it is set to, its custom folders, its names (This PC, Settings, Recent Items), grouping and row height; the picture hangs over the menu's top edge.
- The pinned programs are StartAllBack's, in its order; Pin to / Unpin from Start menu go through Windows' own pin handler, as StartAllBack does.
- Search leaves out programs, files or the public folders as Windows' Start-menu search settings say; recent programs and recent items follow Windows' settings for keeping them.
- A change in StartAllBack's configuration reaches Pathweft's menu at once, even while it is open.
- Help and What's new describe it.

Compared side by side with StartAllBack 3.9.28's menu (docs/verification/2026-11-27-s6c-side-by-side.md). Remaining differences (recent programs ranking, which programs show a jump-list arrow, the All Programs highlight) are tracked in issue #15; StartAllBack's visual styles follow in S6d.

Pathweft 1.1.113 updates to this release with the light package (`Pathweft-1.1.114-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
