# Pathweft 1.1.34

- Maintenance opens from the brush and uses five bottom summary cards as tabs: Cleanup, Startup, Services, Windows tweaks and optional Windows apps.
- Review Windows state before changing it. Cleanup removes only reviewed unchanged files; supported startup, service and tweak changes preserve exact prior values for Restore.
- Performance history and recent process observations collect automatically with bounded retention and storage, without a recording switch.
- Added per-app CPU/RAM/GPU charts, boot diagnostics, Windows/app/driver changes, local insights and selected-query CSV/JSON/HTML export.
- Folder I/O cards show read/write rates, with detailed coverage information available in their tooltip and analysis view.

No network monitoring, DNS changes, package manager or hardware sensor driver is included. Maintenance actions are explicit; the file browser remains unelevated.
