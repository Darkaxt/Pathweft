# Pathweft 1.1.35

- Tables retain their theme while loading or waiting for confirmation, including disabled states.
- Startup now identifies Run, RunOnce, policy Run, Startup-folder files/shortcuts and scheduled tasks triggered at startup or logon. A Type column identifies each source.
- Supported Startup changes preserve their original registry value, file or task state for Restore. Windows startup approval is respected, and externally changed items are preserved.
- Services shows the installed Windows application-service inventory with service name, startup type and description, replacing the inherited ten-item shortlist.
- Maintenance and Performance are mutually exclusive views. Switching between them updates the toolbar state, and returning to files restores the ordinary browser view.

Maintenance remains read-only until you confirm a selected action. This release does not apply optimization presets or automatically disable services or startup entries.
