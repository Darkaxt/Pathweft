Pathweft 1.1.90 lowers the CPU cost of the open Performance analysis (MONITOR-26).

- The live process tables (CPU and RAM) keep their rows, update the values in place and move only the rows whose order changed, instead of re-sorting and rebuilding the whole table six times for every one-second sample.
- The GPU and folder I/O tables are replaced only when a new sample arrives.
- The difference is largest while a UI Automation client is running (accessibility, grammar, screen-capture and similar tools), because each rebuilt table made Windows deliver automation events for every row. With such a client listening, the client's added cost on Pathweft's UI thread fell by about 43% in the release verification; most of what remains is the announcement of the live values themselves.

Pathweft 1.1.89 updates to this release with the light package (`Pathweft-1.1.90-update.exe`). Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
