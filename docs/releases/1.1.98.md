Pathweft 1.1.98 makes mapped network drives use the index of their share (IDX-21) and keeps a network share's index across restarts (IDX-20).

- A drive letter mapped to a network share is now matched to the index service's folder root for that share (the service, which runs as SYSTEM, knows the share only by its \\server\share path). Pane folder sizes, index search and Analyze space on the letter are answered from the index instead of being measured over the network. A letter the service indexes under its own name (such as a Tresorit drive) is unchanged.
- The index service saves each folder root's index (in its data folder, readable only by SYSTEM and administrators) after a scan, every 10 minutes while it changes and at shutdown. After a restart or an update it answers from the saved index at once and rescans the root in the background; a damaged saved index is discarded and the root is scanned. Removing a folder root deletes its saved index.
- Folder roots on network shares are listed with up to eight connections at a time.
- Analyze space treats a folder root that is being rescanned as indexed.
- Help (F1) and What's new describe both.

Pathweft 1.1.97 updates to this release with the light package (`Pathweft-1.1.98-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
