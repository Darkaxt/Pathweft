Pathweft 1.1.74 adds Compress…, which lets you choose every compression setting before an archive is written (S49G).

- Archive → Compress…, on disk and inside archives: the archive's name and place, format (ZIP, 7z, RAR, TAR), compression level, method, dictionary and word size, solid block size, CPU threads, and splitting into volumes (presets or a custom size).
- Encryption: a password entered twice or shown, AES-256; 7z and RAR can encrypt the file names, ZIP can choose ZipCrypto. RAR can add a recovery record.
- Every archive is read back before it appears: with a password, each file is decrypted and compared with its original. Volumes are published all together or not at all (7z/ZIP/TAR as name.7z.001…, RAR as name.part1.rar…).
- Delete files after compression sends the originals to the Recycle Bin only after the archive is verified; Ctrl+Z restores them.
- The last settings are remembered, never the password.
- The bundled RAR writer is rars 0.12.3-pathweft.2 (level, solid, header encryption, recovery record, volumes).
- Specification 1.33 records this (ARCHIVE-12).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
