3D previews now present completed frames during continuous dragging, transfer raw
native pixels without PNG compression, and render at the preview's actual size
and DPI. The F3D profile adds anti-aliasing, ambient lighting, ambient-occlusion
shadows and a reflective grid, with transparent composition into Pathweft's theme.
Resize framing preserves camera interaction, and animation controls retain their
existing behavior without changing the scene merely while initializing controls.

Settings now has vertical category tabs and a wider window that preserves the
existing controls' content width. Help automatically highlights the category of
the section being read while scrolling, clicking categories or filtering results.

Native folder Jump List integration was investigated and its S11 implementation
plan documented. It is not installed by this release; StartAllBack is unchanged.

Windows 11 x64. The runtime and native readers are included; preview modules stay
opt-in. Binaries remain unsigned; verify the published checksums.
