Pathweft 1.1.86 adds workspaces, linked panes, expandable and flat browsing, collections, operation history, listing export, path aliases and image marking (S22: OPUS-01..08).

- Workspaces: the sidebar's Workspaces section saves the open tabs of both panes, which pane is active and, when linked, the linked roots. A click replaces the unpinned tabs (pinned tabs stay); a middle click adds the workspace's tabs to the open ones. A saved folder that no longer exists opens at the nearest folder that does, and the pane says so.
- Linked panes: Link panes (folder menu → Tools) takes both current folders as roots. Going into a folder below one root takes the other pane to the same relative folder. A folder with no counterpart is reported in the other pane, and nothing is created or copied. Leaving a root pauses following until that pane is back below it. Re-link at current folders moves both roots; Unlink ends the link.
- Expandable folders and Flat view (View menu): folders expand in place in the Details view (Right/Left keys too), and Flat view lists every file below the folder with a Location column. A folder selected together with items inside it is transferred once. Copying or moving items from folders below the one shown asks whether to keep the folder structure or flatten.
- Collections: named, persistent lists of files and folders from anywhere, sorted into the sidebar's Collections section. Collections can be filled from the item menu or by saving the Drop bin. Missing and offline members stay listed with their state. Remove from collection, Forget missing items, Rename and Remove never touch the files.
- Operation history: History → Operation history… keeps up to 500 operations for up to 90 days, with their real outcome (done, partly done, failed or cancelled), Open folder, and Undo only while the Undo history still holds the operation. Clearing it (Settings → Privacy) forgets only the records.
- Copy as table puts the selected rows, or all of them, on the clipboard with the shown columns. Export listing… writes the listing as CSV or TSV (UTF-8 with a byte order mark). Only the values already shown are written.
- Path aliases: Add alias for this folder… and Path aliases… (folder menu). Typing @name or @name\below in the address bar goes there. A real file or folder of that name wins, and an alias whose folder is missing says so instead of going anywhere else. The address bar suggests aliases as you type @.
- Image marking: the preview header's Mark button, which stays with the preview in picture-in-picture and the floating window, puts the image into the Marked images collection. Previous and next step through the marked images of the listing. In Quick View, M marks and Shift+Up/Down step.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
