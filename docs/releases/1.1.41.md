Scoop obsolete-version analysis now uses Everything's folder-size index. It no
longer builds a per-file deletion manifest or checks consumers during automatic
estimation. If an indexed size is unavailable, it enumerates metadata only.

Clean removes whole obsolete version folders, including contents added or changed
after analysis. It rechecks the current binding and consumers before removal,
preserving current/in-use versions and external persistent data. Temporary files
and download-cache cleanup retain their exact reviewed-file behavior.

The Maintenance button now shows its five summary cards first, leaving the file
browser available. Cards open their sections; Back to files keeps the cards and
analysis queue. Mode switching stays responsive while cancelled work drains.

The hidden-files eye stays visible without an inherited active square in analysis
modes. Disk-analysis command updates use one context-aware state writer, removing
repeated enable/disable changes during statistics refreshes.
