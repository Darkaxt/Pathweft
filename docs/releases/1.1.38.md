Maintenance now groups Windows tweaks into six searchable categories, with
category filtering in the existing pane and the same five summary-card tabs.
The Tweaks card shows applicable recommended actions still pending, independent
of the current filter. Category dropdown text is centered with its arrow.

Recommendations distinguish Keep enabled, Optional, Advanced and Not assessed
from the item's current state. Selected rows explain consequences, applicability
and source; selected services also show native dependencies, service account and
executable. Unknown or unqualified entries are not given a disable recommendation.
There are no automatically selected optimization presets.

Unsupported tweak actions are blocked in both the interface and worker. Restore
continues to use the exact saved original state, including for settings that can
no longer be applied on the current Windows version.

This release also includes the previously completed updater-download cleanup and
disk-analysis refreshing-state correction. Successful installation no longer
leaves every downloaded setup package in runtime temporary storage.
