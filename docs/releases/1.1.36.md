The shield beside Hidden switches Standard and Administrator browsing without restarting Pathweft. One approved, owner-bound helper serves protected folder reads, disk analysis, Maintenance, detailed file I/O and protected editor saves. Standard browsing leaves that session available to other features; **End administrator session** retires it explicitly.

Maintenance now reviews all Cleanup categories when opened and updates its estimate automatically. Cleanup still requires an explicit reviewed action. All Maintenance tables support header sorting, including enabled/disabled state and numeric sizes, while preserving the selected row and sort direction.

Protected editor saves reuse the approved helper and replace the destination atomically while preserving its permissions. The browser remains unelevated; no Windows permissions, UAC policy, service or startup registration is changed by switching browsing mode.
