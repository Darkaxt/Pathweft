Pathweft 1.1.58 gives the command bar one consistent rule.

- While the file panes show, including with the Performance or Maintenance cards at the bottom, every command works as in plain browsing: file commands, hidden files, the administrator shield, panes, preview, and both Performance and Maintenance.
- While a Performance panel or Maintenance category replaces the panes, every command is disabled except the button that opened that view, which leads back. Transfers stays available.
- Previously Maintenance's cards disabled the shield and dimmed Performance, a Performance panel left Maintenance clickable, and hidden files lost its active state in both modes.
- Disabled commands keep showing their on/off state.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
