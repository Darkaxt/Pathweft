Pathweft 1.1.49 fixes Npm package-cache cleanup. Npm writes diagnostic logs
while Pathweft reviews its cache; those logs no longer make an unchanged package
store fail the safety recheck. The preview and removed-byte result now cover
Npm's `_cacache` store, which the native clean command removes. Separate npx
tools, prebuilds and Npm logs remain outside the reviewed action.

While a package manager performs a cleanup without per-entry progress, the
popup shows active indeterminate progress. A rejected preflight or failed
manager command is labeled as a failure, with the reason shown in the popup.
