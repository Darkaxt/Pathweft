# Pathweft 1.1.2

Ctrl+Alt+Space now opens a compact Everything search popup in Pathweft's theme:
one search field with the four matching options and a clean results list showing
name, location, size and modified date. Search updates while typing and more
results load while scrolling. An empty query shows no drive listing.

The duplicate title/settings row, browser navigation, destination input and
action/view/sort bars are removed. Enter or double-click opens a result; folders
and supported archives open in the main manager. Escape dismisses the popup,
Down moves into results, Ctrl+Enter opens the query in a main pane, and Space
still previews a selected result. Transfers remain in the main file manager.

The Windows integration setting's “Restore previous folder handlers” action now
fits its full label instead of inheriting the tab button's width limit.

Existing theme, search integration and folder-routing preferences are preserved.
Windows 11 x64; self-contained .NET 10. The executable and installer are unsigned.
Installer, portable ZIP, matching application/dependency sources, manifest and
SHA-256 checksums are included. StartAllBack and Windows Search migration remain
postponed; context menus and pinned/recent Jump Lists remain separate stages.
