Pathweft 1.1.85 fixes the search popup's focus (WIDGET-03).

- Ctrl+Alt+Space, and the taskbar search box, open the search popup without raising or activating the Pathweft folder window. The popup was owned by the main window; Windows raises an owner with its owned window and gives activation back to it when the popup hides. The popup is now an unowned tool window, so it stays out of the taskbar and Alt+Tab, and dismissing it returns focus to the program you were using. Opening a result's location still brings the folder window forward, as before.
