Pathweft 1.1.99 adds environment variable suggestions to the address field (BROWSE-13).

- Typing `%` in the address field suggests, as Explorer does, the environment variables whose value is a local folder: `%Lo` offers `%LOCALAPPDATA%` with the folder it names. Enter or a click opens the folder; Tab writes `%LOCALAPPDATA%\` so the folders inside it are suggested next.
- Help (F1) and What's new describe it.

Pathweft 1.1.98 updates to this release with the light package (`Pathweft-1.1.99-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent.
