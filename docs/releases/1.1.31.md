Performance cards now open System analysis in the main browser area, with larger
graphs, themed GPU/range selectors and sortable activity tables. Back to files
or Escape restores the existing pane and selection. The compact cards remain
available while inspecting analysis.

Optional recording keeps CPU, physical RAM, individual GPUs, physical-drive
activity and sampled heavy-app observations for 1, 7 or 30 days in Pathweft's
configured data folder. Recording starts off. Recorded summaries, peaks, app
observations and collection events share the same query logic; missing time
remains a gap. Folder/file activity remains live only.

Includes six read-only performance/history MCP tools through the explicit
`--performance-mcp` stdio entry point. No client is activated or configured,
and the endpoint does not start another collector or request elevation. See
the bundled Performance-MCP.md for usage and observation limits.
