Pathweft 1.1.77 adds Explorer-style details columns, file hashes and Copy details (S50), and new-tab improvements.

- Right-click a column header in folders, search results, archives or the space analyzer: Size column to fit, Size all columns to fit, a check for each column, and More… with Windows' own properties (searchable, grouped) and Pathweft's hash columns. Name stays. Columns are kept per kind of view and apply at once to every open tab and pane of that kind.
- Extra columns such as Created, Accessed, Attributes, Owner, File version and Windows properties fill in the background, visible rows first. Online-only (cloud placeholder) files show only what Windows already cached; they are never downloaded for a column.
- Hash columns: CRC-32, CRC-64, MD5, SHA-1, SHA-256, SHA-384, SHA-512, SHA3-256, XXH64 and XXH3-64, in capitals (Settings has Lowercase). Each file is read once for all the hash columns shown; only panes on screen are hashed, the active one and visible rows first, at low priority, one reader per disk. Files over 256 MB (configurable), online-only files and network locations show a Hash link instead of being read automatically. Results are kept in a hash cache (up to 100 MB, in Pathweft's data folder, never in the files) that Checksum also uses.
- Inside archives, the CRC-32 column shows the CRC stored in the archive; other hash columns are not available there, because computing them would need extracting every file.
- The file menu's Copy entries follow the columns: Copy path, Copy name, then Copy <column> for each column shown (for example Copy SHA-1), and Copy… opens a dialog with pairs, lines, TSV, CSV, JSON, Markdown and checksum-file formats, header row, full paths or names, and case, with a live preview. Choices are remembered. For several files, hashes copy as `hash *name`; hashes not yet computed are computed through the Transfers card first.
- Tabs: the tab menu has Duplicate, and + and Ctrl+T open a new tab at This PC.
- Search: Pathweft notices when Everything stops answering and restarts it, without freezing (SEARCH-05).
- Specification 1.36 records this (COLS-01..05, HASH-01..04, COPY-01..02, TABS-08).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
