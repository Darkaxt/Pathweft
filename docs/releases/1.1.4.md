# Pathweft 1.1.4

- Archive previews use an expandable folder/file tree with Windows icons,
  concise names and file sizes. Branches build their rows when expanded;
  browsing metadata does not extract the archive.
- The opt-in embedded F3D viewer supports the bundled model readers, including
  GLB/glTF, OBJ, STL, PLY, FBX, STEP and others. Model size is no longer capped
  at 64 MiB; relative external resources are supported by the native reader.
  Drag to orbit, right/middle-drag to pan, wheel to zoom, and use Fit/Reset or
  keyboard controls. Animated models expose clip, playback and timeline controls.
- About has an Open settings folder action instead of the Diagnostics expander
  and startup telemetry.

Windows 11 x64, self-contained .NET 10. Application and installer are unsigned.
Installer, portable package, matching application/dependency sources, manifest
and SHA-256 checksums are included. Reader support remains subject to F3D's
format-specific limitations; this is a viewer, not a model editor.
