Pathweft 1.1.61 turns Maintenance › Windows apps into an uninstaller with Bulk Crap Uninstaller's capabilities.

- Inventory: desktop programs from the machine (64- and 32-bit) and current-user uninstall keys, current-user Store packages (main packages only), Scoop apps and Chocolatey packages. Entries without a name, system components, Windows Installer patches and child updates are folded away. Rows show Name, Publisher, Version, Source, State, Size and Installed date, grouped by source; details show the uninstall command, location, registry key or package identity and whether the uninstaller is signed. Reading needs no administrator rights and changes nothing.
- Uninstall one or several: each app's own registered uninstaller runs the way Windows Settings does and requests elevation itself; Windows Installer products use msiexec by product code; Store packages are removed for the current user only; Scoop and Chocolatey use their own uninstall command. Quiet uninstall is used only where the entry declares it or the installer type (Windows Installer, Inno Setup) has documented silent switches. Several apps run one at a time in Bulk Crap Uninstaller's order, after an optional restore point (on by default when a desktop program is included); a Windows Installer uninstall waits if another installation is running. Each app is read again afterwards and reported Removed, Still installed or Cancelled. Pathweft never deletes an install folder as an uninstall and never clicks through an uninstaller.
- Find leftovers: the install folder, product or publisher folders in Program Files, ProgramData and AppData, shortcuts and startup entries pointing into removed locations and the product's Software registry keys, each rated Likely, Possible or Unlikely; only Likely ones are preselected. Files and folders go to the Recycle Bin; registry keys are exported to a .reg backup before removal and Restore imports it. Windows, other apps' locations and folders still used by an installed program are never offered.
- Store apps carry reviewed advice by exact package name from MIT donor ratings (Win11Debloat, Bloatynosy); desktop programs are never recommended for removal. Windows system packages, frameworks, entries without an uninstall command and Pathweft itself are protected.
- Bulk Crap Uninstaller (Apache-2.0) ideas are re-implemented in Pathweft code; its licence, NOTICE and the cited source files with hashes are under vendor/BulkCrapUninstaller. No BCU binary or rating service ships or runs.
- The Maintenance details panel closes with × or Esc, and long lists scroll smoothly.
- Uninstall, the installer-busy guard, cancellation and leftover removal and Restore were qualified in a disposable Windows Sandbox guest with owned fixture programs.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
