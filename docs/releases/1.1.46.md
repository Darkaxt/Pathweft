Scoop Cleanup now completes obsolete-version removal when an ordinary ReadOnly
file stops native deletion. After that failure, Pathweft clears the ReadOnly
bit only on remaining regular members of the obsolete package and retries.
It does not change linked persistent data, current versions or genuine file
locks and permissions.

This follows the 1.1.45 fix for ReadOnly Scoop persist junction names. The
reported host retry removed 14 of 15 remaining obsolete versions in 14.5
seconds; the last MSYS2 version exposed a separate ReadOnly `cacerts` file.

Switching to the Startup Maintenance tab now displays rows already loaded for
the summary card instead of enumerating Windows startup sources again. An
uncached tab shows a loading state while its rows are read. Refresh and
completed actions still reload Windows state.
