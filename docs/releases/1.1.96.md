Pathweft 1.1.96 keeps Analyze space indexed when you switch views (CORE-31).

- Switching between standard and administrator view with Analyze space open no longer measures the whole folder on disk again, which took minutes on a large drive. Like F5, the view switch takes the sizes from the Pathweft index service, which measures every folder for both views; folders written in the last two seconds or not answered by the index are still measured on disk. Ctrl+R still measures everything on disk.
- Help (F1) and What's new describe it.
