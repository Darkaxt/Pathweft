Maintenance Cleanup now inventories obsolete Scoop versions using Everything's
folder-size index without recursively scanning folders whose size is unknown.
Before Clean removes a version, it rechecks the current binding and checks
Windows consumers in a batch. Current, active and persistent data remain
protected.

Clean opens a themed progress window immediately. It shows the current phase,
folder and completed count while Maintenance remains available for inspection.
Cancel stops before the next version; a version already being deleted finishes
before the cancelled outcome appears. Successful cleanup closes the window.

This release also includes the direct Maintenance actions, selectable guidance,
Startup Restore and package Cleanup behavior added during the combined
Maintenance update.
