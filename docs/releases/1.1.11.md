# Pathweft 1.1.11

- Fix application and Win+E helper activation after installation and updates.
  The installer previously passed its RedirectionGuard restriction to the app,
  breaking registered applications reached through user-created junctions, such
  as Scoop's `current` folders. Desktop activation now uses the existing Explorer
  desktop context; the installer retains its protection. File associations and
  Windows security settings are preserved.
- File-open failures appear beside the affected file in a dynamic Message
  column, with the full error in a tooltip. Successful retry clears the message
  and the empty column disappears. Archive entry launch errors use the same UI.
- Bulk working copies, folder-size caches, preview caches and editor runtime data
  use a separate data-drive directory. Small settings stay in Roaming; portable
  and explicit test profiles remain self-contained. Legacy external copies keep
  their paths until released, and remembered sizes remain readable.
- Cancelled or failed archive drags automatically discard materialized export
  copies. Successful external handoffs retain files for their actual consumer.
- Settings > Storage includes Change location. Move the settings and runtime
  data to a chosen data folder, with verified copying and automatic restart.
  Only a small startup pointer remains in Roaming.

Verification covers ordinary file dispatch with the editor on/off, native
association receivers with spaces and Unicode, readable HTML/editor behavior,
directories and archive working copies, rendered error/retry behavior, real
32/64-bit Shell routing and desktop activation, and the actual installer launch
context. The user's media is not played during automated checks.
