Pathweft 1.1.106 lets the top of the preview pane move the window (CORE-35).

- With the preview pane open, its empty top, beside and under the window's buttons, now works like the empty part of the tab row: drag to move the window or snap it, double-click to maximize or restore, right-click for the window menu. The preview's own buttons and the preview below them work as before.
- Help and What's new describe it.

Pathweft 1.1.105 updates to this release with the light package (`Pathweft-1.1.106-update.exe`) when its files are unchanged. Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
