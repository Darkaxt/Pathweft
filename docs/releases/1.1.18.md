# Pathweft 1.1.18

- Full embedded Office page, sheet and slide navigation using bundled Craft
  cores, with LibreOffice fallback for unsupported formats and renderer failures.
- Specialist previews for tables, databases, mail, certificates, app packages,
  design thumbnails, media metadata, binary/ELF files, crash dumps, prefetch,
  Shell classes and compiled help.
- In-app PiP and floating preview windows that preserve the active preview.
- Live nested folder sizes, compact grouped command icons, clearer context menus
  and search-result Open containing folder and native Properties actions.
- Native folder Jump Lists with Quick access and recent destinations, direct
  Pathweft launches, Windows pin/removal ownership and recent-history privacy.

The x64 installer includes the .NET desktop runtime and preview libraries.
Office fallback increases the download and installed size. The application and
installer are unsigned. Source and dependency-source archives accompany the
installer and portable package; SHA256SUMS.txt identifies the delivered assets.
