Pathweft 1.1.60 organises Maintenance › Windows tweaks by goal and marks settings with a cost.

- 81 new individual settings (121 in total), adapted per setting from MIT-licensed projects: Win11Debloat, Sophia Script, SophiApp, WinUtil, Bloatynosy, RemoveWindowsAI and UnattendedWinstall. They cover Copilot, Recall, Click to Do and agent policies; Notepad, Paint and Edge AI; Edge clutter; telemetry, CEIP, Appraiser, Maps and feedback scheduled tasks; app permissions, inking and typing, cloud search and clipboard; File Explorer navigation pane and title bar; Start and taskbar; Delivery Optimization peer sharing and GPU scheduling; and update behaviour (drivers, no automatic restart while signed in). Donor files, licences and hashes are under vendor/. No donor script ships or runs.
- Each setting states its goal (Debloat, Privacy, Performance, Security, Personalize) and its risk: Low, ▲ Caution (reduces a feature, recovery path or update behaviour) or ◆ High (weakens a protection or can break Windows). Caution and High are coloured, keep their symbol and word without colour, need a Yes/No confirmation with No as the default, and are never counted as pending suggestions. Nothing that weakens Defender, SmartScreen, UAC, VBS, Smart App Control, mitigations, BitLocker or Windows Update was adopted.
- Settings backed by scheduled tasks disable only the named tasks; the journal keeps each task's exact enabled state and definition for Restore. A task Windows no longer has is skipped.
- A rule made only of policy values that is present without a Pathweft journal shows "Set outside Pathweft". Restore Windows default removes those values, journaled for Restore; other values under the same policy keys are listed read-only and never removed.
- Every new setting was applied, read back and restored in a disposable Windows Sandbox guest (build 26100), including the task states and a policy reset round trip; the Windows 10-only settings remain Not assessed on Windows 11.

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
