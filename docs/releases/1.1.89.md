Pathweft 1.1.89 adds index status, content coverage and content match locations to Pathweft's read-only MCP (MCP-08).

- `get_index_status`: the index service's own status, with each store's kind, state (loading, scanning, reloading, ready, offline, error, waiting-for-user), items, folders, error and owner.
- `get_content_status`: content index coverage per content-indexed folder (current, pending, stale, failed, unsupported, unavailable, reconciled, added), the store size and the files waiting; it says when no folder is content-indexed. `get_content_state(folder)`: each file directly in a folder, paged.
- `search_files`: structured `updating`, `updating_stores` and `elapsed_us`; `visible_only`; and `locations` (0 to 10), which returns where each matching chunk starts, as stored by the content worker, never text or terms.
- `get_folder_size`: `paths` asks for up to 1,024 folders in one index request.
- All of these are read-only. Content-indexed folders are still chosen only in Settings, and the index service is unchanged.
- Help (F1) has an entry on agents and the MCP.

Pathweft 1.1.88 updates to this release with the light package (`Pathweft-1.1.89-update.exe`). Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
