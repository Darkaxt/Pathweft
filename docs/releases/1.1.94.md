Pathweft 1.1.94 makes Analyze space a snapshot that refreshes when you press F5 (CORE-30).

- Analyze space no longer follows changes on disk. It shows the sizes as they were when it was opened, like WizTree or WinDirStat, so a drive that changes all the time, such as D:\, no longer keeps the processor busy.
- When something changes, the footer says "changed since this snapshot, F5 to refresh". F5 refreshes the analysis from the Pathweft index service and keeps the rows and the selection on screen; Ctrl+R measures everything on disk.
- Help (F1) and What's new describe it.

Pathweft 1.1.93 updates to this release with the light package (`Pathweft-1.1.94-update.exe`). Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
