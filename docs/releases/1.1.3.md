# Pathweft 1.1.3

- Search dismisses when clicking outside, including when WPF retains keyboard
  focus in the query. Focus can move into its preview; leaving that interaction
  dismisses both windows. Escape remains available.
- Dragging ZIP/7z entries between panes sends virtual archive paths directly to
  the existing transfer queue. It no longer extracts the selection on the UI
  thread before starting a drag, which could freeze navigation and start the drag
  late. External OLE consumers can still request real extracted files on demand.
- Downloads in Favorites uses Windows' actual known-folder location and respects
  redirection to another drive.
- Opt-in folder routing retains the canonical Open verb, preserving navigation
  inside an existing Explorer window. Fully owned older registrations upgrade
  while preserving the original recovery state; disabled routing stays off.

Windows 11 x64, self-contained .NET 10. Application and installer are unsigned.
Installer, portable package, matching application/dependency sources, manifest
and SHA-256 checksums are included.
