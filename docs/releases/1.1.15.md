# Pathweft 1.1.15

GLB/glTF animation timelines now omit a held ending when the stored animation
curves show that movement has finished. Internal pauses and later movement stay
included. Right-click the timeline and turn off **Trim idle tail** to use the
original duration. Source models and native animation times remain unchanged.
Uninspectable curves keep their complete range.

The new **HTML** preview module renders static HTML, CSS, local images and fonts,
including relative resources inside compressed folders. Scripts, online content,
forms, popups and downloads are disabled. It uses an isolated WebView2 profile
and streams archive resources without extracting working copies. Disable HTML
under Settings > Files > Preview modules to return to source text.

Qualification covers the reported SNES model, native playback/seek/clip changes,
held/slow/small/late-motion cases, actual local/archive HTML rendering, blocked
resource boundaries, cancellation and native renderer/browser teardown.

The release includes installer, portable application, matching application and
dependency sources, release manifest and SHA-256 checksums. Application and
installer remain unsigned, with source and member hashes recorded in the manifest.
