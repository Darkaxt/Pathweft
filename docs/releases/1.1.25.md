Pathweft 1.1.25 fixes tabs whose local folders disappeared after an update or move.

- Selecting the tab opens its nearest existing parent, climbing as many levels as needed, and remembers the repaired path.
- Restoring a session keeps the tab's position, active state and pin instead of dropping it.
- Unavailable drives, network destinations and access-denied folders retain their location and report availability errors. Existing archive tabs keep their normal behavior.

Windows x64 installer and portable package, matching application/dependency sources,
release manifest and SHA-256 checksums are included. Binaries remain unsigned.
