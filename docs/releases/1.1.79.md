Pathweft 1.1.79 gives the native shell handler one fixed file name (S55, SHELL-06).

- The folder handler is installed as PathweftShell-x64.dll and PathweftShell-x86.dll instead of PathweftShell-<version>-x64/x86.dll. The machine class and Pathweft's per-user folder registration name these files; a per-user registration written by an earlier version is rewritten when Pathweft starts.
- Setup deletes the previous handler. When a Shell caller such as Explorer or a browser still has it loaded, Setup renames it aside (Windows allows that for a loaded DLL) and deletes it at the next restart, so no app is closed or restarted.
- Setup removes the per-version handler files left by earlier releases the same way. Uninstall removes every handler file it can.
- Specification 1.38 records this (SHELL-06).

Update from Pathweft's own updater or run the installer, which requests Windows administrator consent. Pathweft binaries and installer are unsigned; verify the published files with SHA256SUMS.txt and release-manifest.json.
