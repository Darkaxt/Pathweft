# Pathweft 1.1.19

- Consistent themed Settings, Help, What's new and other owned popup windows.
- Immediate update-check feedback, with a clear current-version result or Retry.
- Successful transfers dismiss automatically; unfinished or unsuccessful jobs stay available.
- Analyze space beside Terminal turns the current folder into an expandable size
  tree. Toggle it again to restore the previous view.
- Use available Everything folder totals, with metadata sizing for uncovered
  paths. Indexed coverage is identified explicitly.
- Folder sizes stay visible while refreshing. A bounded memory cache and SQLite
  persistence replace the previous eager loading of the entire size history.
- Windows owns the taskbar/Start menu's Pinned and Frequent folder categories.

The installer includes the .NET desktop runtime and preview libraries. The
application and installer are unsigned. Application and dependency sources,
release manifest and SHA256SUMS accompany the installer and portable package.
