Pathweft 1.1.93 keeps Analyze space on the Pathweft index service when folders change (CORE-29).

- Analyze space on a drive that changes all the time, such as D:\, keeps taking folder sizes from the index service. Before, each change measured the changed folder (after a burst of changes, the whole drive) on disk again, so rows showed Measured, Pending or Updating… instead of Indexed and the processor stayed busy. Only folders written in the last two seconds or not covered by the index are measured on disk. Ctrl+R still measures everything.
- Help (F1) describes it.
