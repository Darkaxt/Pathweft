## Measured cause and correction

Pinned F3D4.0.0 `vtkF3DInteractorStyle::Rotate` invokes `rwi->Render()` for every
mouse event. Feeding all queued samples into that API therefore defeats our
batched capture: hidden baseline PID48752 records24 ordered samples,24 implicit
input renders and689.9208ms of input work before46.1385ms capture and6.5219ms
transfer. Earlier frame-only timings omitted this newly introduced cost.

`Preview/F3dOrbit.cs` adapts the selected fixed-up/temporary-up/pole math without
the immediate draw. Native camera state/pan operations update the actual F3D
camera; every ordered sample is applied before the existing batch capture.
Capture resolution, anti-aliasing, lighting, shadows/reflections, pixel transfer,
frame generation/sequence ownership and cancellation remain unchanged. There is
no timer, reduced quality, dropped input path or coalescing of nonlinear gestures.
The original native input API remains a Debug-only verification oracle.

Hidden PID28160 compares both camera paths on the real161,225,104-byte SNES GLB.
Clockwise/reverse circles, both pole boundaries and panning match within the
explicit specification's numeric tolerance. Ordinary camera differences are
about1e-11; projected up at the native1e-10-degree pole limit differs by at most
7.4e-5 in a component. Position/focal remain strict1e-7; the pole-only up tolerance
is1e-4 (<.006 degrees), accounting for an ill-conditioned projected basis.
The comparison caught and corrected `acos(dot)` losing near-pole precision;
the port uses VTK's stable atan2(cross length,dot) angle calculation.

The same24-sample burst now records zero implicit input renders,2.7734ms input,
25.5179ms capture and3.5971ms transfer at567x814 pixels. Its resulting camera/up/
focal matches the baseline endpoint to numerical precision. Timings are local
samples with cache/GPU-load variance, not display FPS or a general speed claim;
removing24 per-event render requests is the deterministic improvement.

Full gesture workflow PID62544 passes circular/reverse orientation, underside/
