# Release 1.1.79 verification (2026-11-18)

Release: https://github.com/Darkaxt/Pathweft/releases/tag/v1.1.79 (tag v1.1.79 = 5c00d89, main and codex/s8-native-delivery).

**Scope:** S55, SHELL-06 (specification 1.38). The owner asked again why the shell handler is named `PathweftShell-1.1.75-x64.dll`. The handlers are now `PathweftShell-x64.dll` and `PathweftShell-x86.dll`. Setup deletes the previous handler. If a Shell caller still has it loaded, Setup renames it aside and deletes it at the next restart. It also removes the per-version copies of earlier releases. The owner suggested restarting Explorer instead. That was not needed: renaming the file aside covers every caller holding it, including browsers, and closes nothing.
