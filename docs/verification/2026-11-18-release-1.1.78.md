- **Attempts 2–4** (0d905a2): Debug, release publish and packaged checks all built.
- **First S4 run on attempt 2** stopped at the clipboard restore. ClipCascade replaced the clipboard right after the trial restored it.
- **S4 rerun** failed in the S4 clipboard snapshot helper: "duplicate key Format17" (build-fail recorded).
  - **First correction, dfa41fa** (attempts 5, 7, 8), skipped repeated format numbers. It did not fix the failure: the clipboard actually held CF_DIBV5 (17) and a separately registered format literally named "Format17", which collides with WPF's name for format 17. The failure was recorded again.

- Both corrections changed only DEBUG verification code (S4NativeClipboard.cs). The release was rebuilt each time so that its version names the tagged commit.
- The publish identifies itself as `1.1.78+f89e18c3383ff6d8ad7cdbc39e8fc916a31749af`.

Those elevated actions were checked as command construction and refusal only; no install was performed from the test build.
