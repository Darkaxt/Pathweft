# S25 UI quality review, refinement and motion, 2026-11-11

Authority: specification v1.14, UIQA-01..03 and MOTION-01..04. Branch
`codex/s8-native-delivery`. Evidence (local, not committed):
`.local/evidence/2026-11-11-s25/` with `findings.md`, `baseline/` and `after/`
(dark/light/original captures of two-pane, single, narrow, Performance,
Maintenance, preview, icons and every Settings category; timings).

## Method
The Debug-only harness `S25Verification.cs`, run through the hidden appearance
trial, times ordinary browsing paths in-process with an Input-priority heartbeat
(longest UI-thread gap) and captures every main surface per theme. The same
harness ran before any fix (`s25-baseline`) and after (`s25-refinement`,
`s25-tuning`, `s25-qualification`). The host carried 32-70% CPU load from
unrelated processes; the idle-control heartbeat (19-36 ms) is the noise floor.

## Measured result (dark native theme, two panes; max UI stall)
| Path | Before | After |
| --- | --- | --- |
| Open System32 (first) | 1701 ms | 370 ms |
| Revisit System32 | 664-1369 ms | 301-373 ms |
| Open WinSxS (25k folders) | 19259 ms | 726 ms |
| Select 200 rows | 23-30 ms | 20-32 ms (97 ms first, warm-up) |
| View modes | 354-500 ms | 304-414 ms |
| Statistics/Performance | 11-39 ms | 10-37 ms |
| Maintenance toggle | 303-562 ms | 51-118 ms |
| Resize x20 | 23-26 ms | 21-29 ms |

The first refinement run measured selection and view modes slower; the deferred
selection pass was reverted and thumbnail batches reduced (`s25-tuning`), and
the final run shows no path worse than baseline beyond the noise floor.

Motion with animations on: 539 frame intervals inside transition windows,
p50 4.5 ms, p95 13.2 ms, max 33.6 ms. Rapid Statistics/Performance reversal ends
on a single face. Settings → Animations off or Windows animation effects off
apply state changes immediately (Motion.On gate; harness timings run with
animations off).

## Findings
Every finding is fixed or rejected with a reason in `findings.md`. Fixed:
coalesced size-arrival summaries, one-pass footer, batched background hand-back,
cached/frozen brushes and glow, Performance card density guard, focus/pressed/
disabled states for Ghost and Tab buttons, lighter light-theme cards, dimmed
custom accent controls under the Windows accent, "color" spelling, Drop bin
alignment, empty-folder/no-results/filter states, softened file-type, age and
transfer colours, Windows folder yellow in the summary widgets, and soft
transitions (summary cards, Statistics/Performance, Maintenance, Settings
categories, Performance analysis tabs, preview panel). Token migration (type,
radius, spacing) is rejected for S25 as having no rendered defect behind it.

## Limits
Captures are at the host's 150% scale; 100% was not separately rendered in this
stage. Frame pacing was measured on this host's display only. Timings are
in-process Debug measurements on a loaded host, not a profiler trace.

Regression suites on the final Debug build: the default hidden appearance trial
(45 checks) and the summary-strip suite (`PATHWEFT_VERIFY_STATS_ONLY`, 24 checks)
passed. The S4 file-UI suite was not run in S25 (it requires its own registered
scratch build).
