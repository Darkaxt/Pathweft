# S6a guest verification: Pathweft's Start menu beside StartAllBack

Source: `3735ce7` (debug build, ticket c3ffa11b attempt 2). Plan S6a, spec SAB-02 (opening and closing), SAB-04, SAB-05 (guest). Not released: S6a ships together with S6b.

## Guest

- Coordinator Windows Sandbox gate, 4096 MiB, networking off, ticket `f315db37`. Read-only inputs: the host .NET runtime and the debug build output.
- StartAllBack 3.9.28 copied from the host install folder without its Cache folder, licensing or registry state (main DLL SHA-256 `8c26c722…e1b7`, the same as the host; signature valid), installed with `/install /silent /allusers`; the owner's Start-menu presentation values applied (as in the 2026-11-26 probe) and Explorer restarted, which loaded StartAllBack.
- `Pathweft.exe --agent` from the debug build with `startmenu=1` in the guest user's settings. Input came from WinApp CLI `send-input` (injected, not physical).

## Results

| Case | Pathweft menu | StartAllBack menu | Foreground |
|---|---|---|---|
| Baseline, no helper: lone Win | none | opened | StartAllBack's |
| Helper started | state file: hooks on, 1 orb found | closed | unchanged |
| Lone Win, desktop in front | opened at the orb, above the taskbar | stayed closed | Pathweft's menu |
| Win again | closed | stayed closed | the previous window |
| Ctrl+Esc | opened | stayed closed | Pathweft's menu |
| Esc | closed | stayed closed | the previous window |
| Orb press, menu closed (desktop, and StartAllBack's configuration window in front) | opened | stayed closed | Pathweft's menu |
| Win+R with the menu open | hid on deactivation | stayed closed | Run |
| Lone Win with Run in front, then Esc | opened, then closed | stayed closed | Pathweft's menu, then Run |
| Explorer restarted | orbs re-read on TaskbarCreated (state rewritten); the new orb opens the menu | stayed closed | Pathweft's menu |
| Orb press with the menu open | closed | stayed closed | another window |
| Helper stopped through its shutdown signal, then lone Win | none (state file removed) | opened | StartAllBack's |
| Setting off: the helper exits at once (exit 0, not ready), then lone Win | none | opened | StartAllBack's |
| Helper killed (crash), then lone Win | none | opened | StartAllBack's |

Found by this check: with attempt 1 the menu kept its full height on the guest's small screen (work area 239 pixels high), covered the taskbar and its orb, and an orb press could not close it. `StartMenuWindow.Place` now fits the menu inside the work area (3735ce7); attempt 2 ends it at the taskbar's top (0,0,400,239) and the orb press closes it.

The guest scripts, observations and session log are in `.local/research/startallback/s6a-guest-20261127/`.
