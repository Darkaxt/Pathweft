## Verification and corrections

The final complete hidden workflow returned result 0 and recorded zero foreground
events for the test process. Its real actions, layout captures and mixed-DPI
checks ran together. The separate native-input/Explorer trial intentionally
allowed only its search popup to take focus; it is not described as invisible.

Earlier opacity-based trial windows exposed gray frames and were rejected.
Debug presentation now places rendered windows beyond the virtual desktop and
hides the native HWND during monitor measurement. A trace then identified WPF
HwndTarget.OnDpiChanged calling SetWindowPos without SWP_NOACTIVATE. The final
Debug-only, UI-thread-local CBT guard vetoes activation solely for explicitly
noninteractive trial HWNDs. The native focus trial is excluded from this guard.
The failed trace and passing zero-foreground/DPI results are retained privately.
This guard is absent from Release. See Microsoft's
[SetWindowPos activation contract](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos).

Direct layout inside the native DPI event had also reentered virtualized row
generation. The popup now schedules one coalesced layout operation after WPF's
native layout processing. Actual mixed-DPI transitions pass without that crash.
Content-only screenshots that lost the background were discarded as visual
acceptance evidence; the final captures render the actual WPF Window.

Focused scope/taskbar contracts passed. The taskbar regression first reproduced
acceptance of nonintersecting shell coordinates, then passed after safe placement
was made to require intersecting measurements. Scale/bounds/occupied-control and
fully occupied/unmeasured cases also passed.

Debug and Release builds passed with SDK 8.0.427. The only compiler diagnostics
were the three inherited CS0108 member-hiding warnings, emitted during both WPF
compilation passes. The Release source self-test passed, including reset-key
ownership and real filesystem/transfer contracts. Earlier S1 index/clipboard/OLE
evidence remains applicable to unchanged paths; no unrelated physical clipboard
or drag trial was repeated.

Private evidence under `.local/evidence/2026-10-28-s2/` retains the final hidden
workflow, native Explorer lifecycle, DPI results, screenshots/layout trees,
donor hashes, verified source hashes and compiler receipts. These are ongoing
S5 comparison evidence, not expendable build trees or public sample data.
