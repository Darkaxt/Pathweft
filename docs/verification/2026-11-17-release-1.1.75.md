# Release 1.1.75 verification (2026-11-17)

Release: https://github.com/Darkaxt/Pathweft/releases/tag/v1.1.75 (tag v1.1.75 = 3f11ff3, main and codex/s8-native-delivery).

**Scope:** S49H, the owner's reports after 1.1.74 (SPACE-11, specification 1.34):
- "while using the space analyze if I click in the very same tab, the folder gets reset to the default view breaking free from the disk analyzer mode. So I cannot effectively mode to other tabs without losing the work?"
- "Supr button doesn't work on the tree nodes. I wanted to delete "C:\ProgramData\Hogwarts Legacy" and I need to use the context menu for that"
- "The context menu also doesn't do anything... no confirmation popup or anything"

## Diagnosis

`C:\ProgramData\Hogwarts Legacy` had in fact gone to the Recycle Bin, deleted from C:\ProgramData on 17/11/2026 at 22:05. Pathweft, like Explorer, asks for no confirmation by default. The deleted row stayed in the analysis until a full re-measurement, so the delete looked as if it had done nothing, and a second Delete really did nothing because the path was already gone.
