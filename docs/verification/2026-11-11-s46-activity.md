# S46 verification - startup task, startup administrator access, app activity (2026-11-11)

Release 1.1.54 from commit 7cbf76e (spec 1.16).

- Builds (Coordinator .NET gate): Debug qualification build and the self-contained
  Release publish plus PackagedChecks probe (stage s46-release-1.1.54) exited 0 with
  verified process-tree exit.
- ACTIVITY-04 burst, published recorder, elevated through the administrator broker,
  isolated profile, 32 logical processors: 2,400 `cmd /c exit` in 29.7 s (about
  4,850 starts per minute). Recorder 0.018% normalized CPU (0.58% of one core)
  during the burst, 0.008% idle; private memory 25.0 MiB idle, 26.1 MiB after the
  burst, 21.7 MiB at the end. Lost events, missed starts, unmatched stops and dropped
  batches all 0; exactly 2,400 cmd.exe starts recorded, none without a path. The
  burst was synthetic (short processes), not a real parallel build.
- Findings fixed during qualification: version 4 of the Kernel-Process start event
  carries a mandatory-label SID before ImageName, which TraceEvent's registered
  template cannot decode (every path was "(unknown)"); the path is now read from the
  raw payload. Recorder memory was 40 MiB before SQLite cache limits and a heap
  compaction after each batch.
- MCP: all five activity tools answered over `--performance-mcp` against the test
  store; workloads roll up as expected (for example one Reframe root with 641
  processes, 417 counted as short).
- CPU time derived from cycles matched measured process CPU time (4.01 s vs 3.98 s).
- Task Scheduler: a standard user registered and read back a root-folder logon task
  with the same definition (priority 4, IgnoreNew, InteractiveToken, exact action) and
  deleted it; highest-privilege registration is refused unelevated, as designed (the
  recorder task is registered through the administrator session).
- Harness on the Debug build (UI code identical to the release commit; differs only
  in start-event decoding, version and documents): default 45/45, Statistics 24/24,
  S25 6/6.
- Corresponding sources verified (2,144 git blobs, 1,518 dependency sources and
  notices, 7 Office engines, 371 dependency archives). Package checks on the portable
  delivery: 2,420 passed, 0 failed, including the eleven-tool MCP surface and real
  activity queries. No install trial was run.
- Published at https://github.com/Darkaxt/Pathweft/releases/tag/v1.1.54 (not a draft
  or prerelease); all six assets downloaded independently match SHA256SUMS.txt and the
  local package byte for byte.
