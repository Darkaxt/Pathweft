## Qualification limits and corrections

Native mutation tests used disposable guest/task-owned fixtures. Host UAC consent
was not automated, no real host package was removed, and host System Protection
was not changed to force a restore-point success. Windows can decline those
requests; their native result is surfaced rather than reported as success.

The first narrow-layout assertion exposed clipped content; the finite scrolling
layout and compact descriptions/cards now pass. Natural close exposed a nested
WPF Closing call; dispatching the second close after cancellation resolves it.
Malformed journal handling, strict imported-selection validation and the hard-link
skip rule were corrected and rechecked without weakening their criteria.
Chart shutdown also separates background reads from their UI continuations:
synchronous window close drains native reads without deadlocking on presentation
queued to the closing UI thread. Final app177288 exercises that exact boundary.

## Scope and closure assessment

No new background sampler, recording switch, remote listener, MCP activation,
network/DNS feature, winget integration, driver or thermal reader is introduced.
Maintenance actions require explicit confirmation; privileged work is scoped to
an authenticated short-lived worker. The existing expandable size-sorted
Diskweft tree and duplicate tools are preserved.

The source remains in the current WPF UI and existing sampler/history ownership.
The small native maintenance boundary serves the current privileged operations;
no generic command framework or additional architecture is required at closure.
Screenshots/receipts are retained for user validation; expendable builds, guest
scratch and isolated test profiles are cleaned through reviewed helper tickets
after their final consumers exit.
