# Release 1.1.105 verification (S58: OPUS-09, OPUS-09a, OPUS-10)

Source: `2cd17c4` (tag `v1.1.105`). Plan S58, spec 1.66.

## Scope

Batch editing of embedded metadata: Right-click → Tools → Edit metadata….

- `Notes/EmbeddedMetadata.cs` reads and writes through each file's registered Windows property handler. It covers the OPUS-09a matrix of photos, music, video and Office documents. Dates can be set or shifted. Every write is read back, and Undo puts the earlier values back through Restore.
- `Notes/MetadataDialog.cs` shows mixed values, a review, Apply with Stop and the results per file.
- The edit goes into Undo (kind `meta`, kept in undo.json) and Operation history.
- `ShellProperties.Read` placeholder flag fix: GPS_FASTPROPERTIESONLY 0x8, which was GPS_READWRITE 0x2.

## Findings (FLAC property handler, probed on scratch copies)

- Each save replaces the file, so the file gets a new NTFS file ID.
- Writing Contributing artists also stores Album artist.
- When several details are removed in one save, the handler drops some of the removals (seen with 2, 3 and 4 details together). A removal saved alone always held.
- Rating is reported writable but is not kept.
