labelled writable or read-only, and no user file is opened for writing to probe
permissions. A locked archive icon describes contents/capability; its container
can still have ordinary filesystem operations available.

include filtered candidates. Inaccessible/offline Windows attributes remain

finding retains its other System/cloud/link exclusions and uses visibility when
