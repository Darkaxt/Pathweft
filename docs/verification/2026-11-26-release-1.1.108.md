- `MainWindow.xaml`: the preview column beside the panes is removed. `Chrome.cs`: the caption no longer accounts for the preview (CORE-35 revised: the tab row's empty part drags the window).
- `PreviewCardsVerification.cs` (new); PreviewCorrection, PreviewModes and packaged checks moved to the new hosts.
