# S6b guest verification: Start menu contents, search, power and folder routing

Source: `c2f08d2` (debug build, ticket 68d41ce1 attempt 2, renewed from 98a06a94 after its correction limit). Plan S6b, spec SAB-02 (contents), SAB-03, SAB-06. Released with S6a as 1.1.113.

## Guest

- Coordinator Windows Sandbox gate, 4096 MiB, networking off; six runs, one per build. Read-only inputs: the host .NET runtime and the debug build output.
- StartAllBack 3.9.28 installed as in the S6a check (no Cache folder, licensing or registry state copied), the owner's Start-menu presentation values applied.
- Guest-only seed: a Start menu folder "S6b Tools" with new programs, a pinned Notepad and File Explorer, recent files, UserAssist history. The guest has no Pathweft index service (the index-missing notice path).
- `Pathweft.exe --agent` with the setting on. Input came from WinApp CLI (`send-input`, UI Automation invoke/hover/right-click; injected, not physical).

Found by this check, fixed before the final build:

- Run 1: duplicate All Programs entries; dim text in the helper (palette not initialized); new-program highlight missing; keyboard focus in jump lists.
- Run 2: highlight backgrounds hidden by the button template; an open flyout or submenu did not give way to hovering another row; the Windows 7 item menu items (Pin/Unpin, Remove from this list, Properties) were missing.
- Run 3: a menu opening under a resting pointer over All Programs opened the flyout, which took the keys typed for search (4dab5fc).
- Run 4: Esc closing the flyout under a resting pointer made it reopen at once, so Esc could not close the menu (15a6b85).
- Run 5: the guard of 15a6b85 was armed after WPF reported the pointer entering; it now reads the real cursor whenever a hover action is due (c2f08d2).

Host index check (read-only): the six file-group queries of `StartMenuSearch.FileGroups` for "release" through the installed index service's `pwindex query` answered with Folders 7077, Documents 1907, Pictures 53, Music 101, Videos 85 and Files 9349 matches, each in about 110-125 ms. This checks the group expressions against the owner's index; the menu's own client call with real results is seen in S6e.

Open file location of pinned Notepad opened the pinned shortcut's folder: the guest has no `notepad.exe`, so the shortcut target is missing and the shortcut itself is shown; Command Prompt covers the target case.

Screenshots and guest scripts are in `.local/research/startallback/s6b-guest-20261127/` (run2 to run6).
