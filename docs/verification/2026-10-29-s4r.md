version 0, so earlier nominal fixtures were replaced before final qualification.
Rewrites retain the source family and qualified metadata; identical compressed
bytes are not promised.

Embedded old-style legacy member comments remain read-only: the original
source-built fixture itself triggers an UnRAR comment error. That error is not
waived. Qualified legacy fixtures retain archive comments; modern fixtures also
retain member comments. This finite matrix does not establish universal RAR parity.

## Clipboard and lifecycle reconciliation

The integrated trial exposed unreliable transfer-format round trips. Publication
now materializes native HGLOBALs before opening the clipboard with a live window
owner. Windows owns successfully published handles. File-list reads use the
standard Shell decoder; virtual selection is UTF-8 and drop effect is a DWORD.
Older asynchronous copies/completed cuts cannot overwrite newer sequences.
Access refusal reports failure without dispatching a transfer.

The harness waits for observed Windows availability after read refusal, without
repeating successful Copy or introducing a cancellation deadline. Finite rollback
uses saved native data, a sequence guard and an independent process. The final
post-exit reader matched all seven captured formats. Earlier failed diagnostics
are not acceptance evidence. The speculative custom file-list decoder was removed.

Inherited member-hiding compiler warnings remain. Hidden listener actions do not
establish physical popup placement, focus or keyboard behavior.
